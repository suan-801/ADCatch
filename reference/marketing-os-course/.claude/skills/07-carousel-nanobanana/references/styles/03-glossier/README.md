## 핵심 시각 코드
- 글로시 핑크/누드 베이지/크림/살구 BG
- 한글 세리프 (Noto Serif KR) + 영문 디스플레이 세리프 ("GLOSSIER", "DEW") 혼합
- 다크 브라운/플럼 텍스트
- 풀블리드 글로시 매크로 또는 모델 라이프스타일 (손·입술 클로즈업)
- 골드/브론즈 영문 로고 마크
