## 톤 키워드
데이터 · 임상 · 신뢰 · 큰 숫자 · 그리드 · 프로바이오틱

## 핵심 시각 코드
- 콜드 그레이/클리니컬 블루 틴트 BG
- 차콜 텍스트 + 클리니컬 블루/임상 그린 액센트 (수치 강조)
- 큰 숫자 디스플레이 ("3", "82%", "4주") - 슬라이드 30-50% 차지
- 한글 산세리프 + 영문 Helvetica/Inter
- 제품 라인업 그리드 (3-5개) + 차트·바 그래프 미니 + 미생물 일러스트
- 작은 출처·단위 footnote (`*임상 N=30`)

## Best for
임상수치·결과 강조 · N개 제품 비교 · 더마·기능성 화장품 신뢰 톤
