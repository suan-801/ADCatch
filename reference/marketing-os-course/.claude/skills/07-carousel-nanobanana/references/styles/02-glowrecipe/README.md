# 02-glowrecipe — 컬러 블록 빅 타이포 (Glow Recipe 톤)

**브랜드 앵커**: @glowrecipe (US K-뷰티 비비드 컬러·과일 모티프)
**호출 자연어**: "글로우레시피 스타일", "컬러 블록", "비비드 컬러", "과일 모티프"

## 톤 키워드
컬러 풀 · 임팩트 · 후크 · 과일·식물 모티프

## 핵심 시각 코드
- 풀 컬러 블록 BG (워터멜론 핑크/망고 옐로우/아보카도 그린/블루베리)
- 빅 한글 산세리프 (한 줄 2-3자)
- 과일·식물 일러스트 모티프 (키 인그리디언트 비유)
- 제품 가장자리 trim 또는 풀컬러 빠짐
- 작은 라벨 박스 + 큐트한 손글씨 디테일

## Best for
첫 슬라이드 후크 · 단일 키 인그리디언트 · 리스트형 표지 · 임팩트 강한 Hook
