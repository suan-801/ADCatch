# 카드뉴스 CTA 라이브러리 — SNS 행동 유도형 6종

> 본 파일은 07-carousel-nanobanana 스킬이 CTA 슬라이드(마지막 1장) 텍스트를 도출할 때 1차 풀로 사용한다. SNS 카드뉴스는 **유료 광고의 가격·할인 직접 노출**과 다르게 저장·공유·댓글 등 **무료 도달 KPI** 를 유도하는 게 디폴트. 직접 가격은 캡션 본문에서만.

---

## 1. CTA 6종 풀

### ① 저장 유도 — 가장 안전한 디폴트

```
"이 카드 저장해두세요"
"📌 저장하고 4주 챌린지 시작"
"나중에 다시 보려면 저장 →"
```

- **KPI**: 저장 (IG 알고리즘 가산점 ↑)
- **적합 골격**: 리스트형·정보형
- **시각**: 북마크 아이콘 + 화살표

### ② 공유 유도

```
"친구에게 공유 →"
"30대 친구에게 보내주세요"
"이런 게 필요한 사람에게 ↗"
```

- **KPI**: 공유·DM 전송
- **적합 골격**: 스토리형·정보형
- **시각**: 페이퍼플레인·DM 아이콘

### ③ 댓글 유도

```
"당신은 어떤 페인이 있나요?"
"몇 번 항목에 공감?"
"댓글로 알려주세요 ↓"
```

- **KPI**: 댓글·인게이지먼트
- **적합 골격**: 스토리형·리스트형
- **시각**: 말풍선·물음표

### ④ 프로필 방문 유도 (링크 클릭)

```
"프로필 링크에서 자세히 →"
"@[브랜드명] 프로필에서 만나요"
"링크 인 바이오 ↗"
```

- **KPI**: 프로필 클릭·랜딩 유입
- **적합 골격**: 정보형·스토리형
- **시각**: 화살표·프로필 아이콘
- **주의**: 링크 자체는 캡션에. 슬라이드에 URL 직접 표기 ❌ (가독성 ↓)

### ⑤ DM 유도

```
"DM으로 시크릿 가격 받기"
"질문 있으면 DM 주세요"
"DM '광채' 보내주세요"
```

- **KPI**: DM 인입·1:1 전환
- **적합 골격**: 스토리형
- **시각**: DM 아이콘·이모지

### ⑥ 시리즈 다음 편 안내 (리텐션)

```
"다음 편: <제목>"
"내일 9시에 만나요"
"시리즈 ② 예정"
```

- **KPI**: 팔로우·리텐션
- **적합 골격**: 시리즈 콘텐츠
- **시각**: 캐러셀 시퀀스 표시·캘린더 아이콘

## 2. CTA 슬라이드 = 직접 가격 ❌ 룰

CTA 슬라이드 (마지막 슬라이드 시각 영역) 에 다음은 ❌:

- `28,900원` 같은 직접 가격
- `35% OFF` 같은 % 할인 표기
- `1+1 / N+N` 같은 번들 직접 노출

대신:
- "시크릿 가격 ➡ 프로필 링크" (가격은 캡션 본문에)
- "런칭 기념 한정 →"
- "프로필에서 단독 가격 확인"

> 광고 이미지(05a) 는 5단 카피의 5단(CTA 풀바)에서 가격·할인을 시각 영역에 시각화 가능 (직접 응답·전환 광고 룰). **카드뉴스(07)는 오가닉 SNS 콘텐츠**라 가격 직접 노출 시 IG 알고리즘 도달률 하락 + 광고 표시 의무 위반 리스크.

---

## 3. CTA 슬라이드 텍스트 캡

`text-density-caps.md` § 1 에 따라:
- CTA 헤드 ≤6단어 / ≤12자
- CTA 부연 ≤20자 × 1줄

예:
- ✅ "이 카드 저장 →" (8자 + 화살표)
- ✅ "프로필 링크에서 자세히" (11자)
- ❌ "4주면 광채가 보이는 시크릿 세럼, 프로필 링크에서 만나요" (28자 — 본문에 가깝)
