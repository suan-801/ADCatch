# 슬라이드 레이아웃 풀 — Hook · 본문 · CTA 각 5종

> 본 파일은 07-carousel-nanobanana 스킬이 슬라이드별 NanoBanana 프롬프트 [5] LAYOUT 블록을 합성할 때 1차 풀로 사용한다. 슬라이드 1장 = 레이아웃 1개. 같은 카드뉴스 시안 안에서 Hook·본문·CTA 슬라이드의 레이아웃 패밀리는 통일 (예: 모두 좌측 정렬 + 동일 그리드).

## Hook 슬라이드 레이아웃 6종

| ID | 이름 | 특징 | 적합 골격 |
|---|---|---|---|
| **H0** | **★ Reference Mockup (2026-05-11)** | reference 의 prop 인벤토리 (폴라로이드 + 바인더클립 / 잡지컷 + 마스킹테이프 / 명함 + 클립 / 책 표지 + 띠지 등) 를 **그대로 재현**. 마스트헤드·거대 헤드라인 임의 추가 ❌. 캡션은 reference 픽셀 점유 비율 그대로 (보통 < 15%) | 모든 골격 — reference 가 mockup 패턴일 때 H1~H5 우선 |
| H1 | **빅 타이포 솔리드** | `BRAND-Signature` 또는 `BG-Deep` 솔리드 배경 + 헤드 1줄 풀블리드 (60~80pt 상상). 다른 요소 거의 ❌ | 정보형·리스트형 |
| H2 | **질문 + 제품컷** | 좌상단 질문 헤드 + 우측 제품 reference 정면컷 (AS-IS) + 부유 소품 1~2개 | 정보형·스토리형 |
| H3 | **숫자 후킹** | "3가지" / "4주" / "84%" 등 큰 숫자가 시선 중심 + 부제 1줄 | 리스트형·정보형 |
| H4 | **페인 인용 카드** | 따옴표 + 페인 한 문장 ("잡티가 더 진해진 30대...") + 손글씨 느낌 폰트 | 스토리형 |
| H5 | **비포애프터 분할** | 좌/우 또는 상/하 분할 + 헤드 띠 | 정보형·스토리형 |

> **H0 트리거 신호** (둘 중 하나라도 충족 시 H1~H5 보다 H0 우선):
> - reference 5축 분석의 `PROP INVENTORY` 에 물리 오브젝트가 **2개 이상** 등장 (예: 폴라로이드 + 바인더클립 + 손글씨 메모)
> - reference 의 텍스트 점유 픽셀 비율 < 15%
>
> **H0 프롬프트 합성 룰**: [3] EFFECT 블록에 PROP INVENTORY 항목을 verbatim 으로 박는다. NanoBanana 의 [5] LAYOUT 어휘는 "literal reproduction of the reference mockup composition — do not invent a new headline or masthead that does not exist in the reference" 로 시작.

## 본문 슬라이드 레이아웃 5종

| ID | 이름 | 특징 | 적합 골격 |
|---|---|---|---|
| B1 | **헤드 + 본문 + 제품** | 상단 헤드 1줄 + 본문 2줄 + 하단 제품 reference 컷 (썸네일 사이즈) | 정보형 |
| B2 | **항목 카드** | 큰 번호(①②③) + 항목 헤드 + 1줄 부연 | 리스트형 |
| B3 | **인용 + 텍스처 매크로** | 텍스처 매크로 배경 (제형 reference) + 텍스트 오버레이 | 정보형·스토리형 |
| B4 | **다이어그램·인포그래픽** | 화살표·아이콘·플로우 + 텍스트 라벨 | 정보형 |
| B5 | **풀블리드 사진 + 캡션** | 사진 (제품 reference 또는 라이프스타일) 풀블리드 + 하단 흰 띠 + 1줄 캡션 | 스토리형 |

## CTA 슬라이드 레이아웃 5종

| ID | 이름 | 특징 | 적합 행동 유도 |
|---|---|---|---|
| C1 | **솔리드 CTA 카드** | `BRAND-Signature` 솔리드 + 흰 텍스트 1줄 + 화살표 | 프로필 링크·DM |
| C2 | **저장 유도 카드** | "이 카드를 저장해두세요" + 북마크 아이콘 + 요약 한 줄 | 저장 KPI |
| C3 | **공유 유도 카드** | "친구에게 공유" + 페어컷 (자/캡슐) | 공유 KPI |
| C4 | **댓글 유도 질문** | 질문 1줄 + 댓글창 일러스트 ("당신은 어떤가요?") | 댓글 KPI |
| C5 | **시리즈 다음 편 안내** | "다음 편: <제목>" + 캐러셀 시퀀스 표시 | 리텐션 |

> ⚠️ CTA 슬라이드에 **직접 가격·% OFF 표시 ❌** (`banned-words.md` § 2 룰). 가격은 캡션 본문에서만.

## 시안 일관성 강제 룰 (N장 전체)

같은 시안 내 N장 슬라이드는 다음 5개를 통일:

1. **배경 컬러·텍스처** — `brand_brief.md § 4-1` 6슬롯 중 동일 슬롯 사용. 슬라이드별 컬러 다양화 ❌
2. **타이포 패밀리** — `brand_brief.md § 4-4` 폰트 1패밀리 + 위계만 변화 (Hook 80pt / 본문 40pt / CTA 60pt 상상)
3. **여백·그리드** — 좌/우 마진 동일 (예: 8% 좌우 마진)
4. **반복 모티프** — 시그니처 소품 (캡슐 알갱이·꽃잎·스파클 등) 슬라이드마다 등장 / 또는 색 띠·코너 장식 반복
5. **로고 위치** — 모든 슬라이드 동일 위치 (예: 좌하단 작게)

NanoBanana 호출 시 `system_instruction` 또는 프롬프트 상단 공통 헤더에 위 5개를 명시.

## 슬라이드 시퀀스 발번호 (★ 시안 일관성 강화)

선택적으로 슬라이드 우상단·하단에 페이지 인디케이터 추가:
- "1 / 5", "2 / 5", ... 또는 점 5개 (현재 페이지 강조)
- IG 카루셀 UI 가 이미 점 인디케이터를 보여주므로 중복 시 ❌
- LinkedIn·Facebook 은 인디케이터 직접 그리는 게 좋음

## 트렌디 한국 카드뉴스 레이아웃 패턴 (2025)

### ✅ 권장

- 좌측 정렬 + 충분한 여백
- 1슬라이드 1메시지 (글자 3줄 미만)
- 핵심 단어만 컬러 강조 (시안 1장 = `BRAND-Signature` 1포인트)
- 손글씨·뱃지·말풍선 캘아웃
- 흑백 베이스 + 1포인트 컬러 (`BRAND-Signature`)

### ❌ 피하기

- 풀 컬러 그라데이션 배경 (정보 가독성 ↓)
- 빽빽한 본문 텍스트 (3줄 이상)
- 슬라이드마다 다른 폰트
- 과한 3D 효과·드롭쉐도우
- 정중앙 빽빽한 정보 (좌측 정렬·충분한 여백 권장)
- 스톡 포토 룩
