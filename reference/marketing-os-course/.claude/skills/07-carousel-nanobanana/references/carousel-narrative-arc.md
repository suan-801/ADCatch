# 카드뉴스 내러티브 아크 — Hook → 본문 → CTA 골격

> 본 파일은 07-carousel-nanobanana 스킬이 N장 슬라이드 시퀀스의 **스토리 골격**을 도출할 때 1차 풀로 사용한다. 카드뉴스는 1장 후킹 광고와 달리 **N장 정보 흐름**이 핵심 — 슬라이드 1장당 1메시지, 전체가 하나의 아크를 이룬다.

---

## 1. 3개 시그니처 골격 (정보형·스토리형·리스트형)

카드뉴스 시안 1개 = 골격 1개 기반. 토픽 성격에 따라 매칭:

### 골격 ① — 정보형 (Information-First)

```
[후킹 질문/충격적 사실] → [원인 분해 N-2장] → [해결 약속·제품·CTA]
```

- 적합: 성분 교육 / 카테고리 입문 / 트렌드 해설 / "왜 X가 중요한가"
- 5장 매핑: 1장 후킹 질문 / 2장 문제 원인 / 3장 메커니즘 / 4장 솔루션·제품 / 5장 CTA
- 예 ([브랜드명]):
  - 1장 "왜 28일 턴오버를 안 기다리세요?"
  - 2장 "각질이 쌓이는 진짜 이유"
  - 3장 "캡슐 알갱이가 톡 터지며"
  - 4장 "4주면 광채가 보입니다"
  - 5장 "프로필 링크에서 시크릿 가격 →"

### 골격 ② — 스토리형 (Story Arc)

```
[감정 후킹·페인 인용] → [고객 여정 N-2장] → [반전·결과·CTA]
```

- 적합: 페인 공감 / 후기 구성 / 비포애프터 / "30대 여성 한 명의 이야기"
- 5장 매핑: 1장 페인 한 줄 / 2장 시도해본 것들 / 3장 발견·전환점 / 4장 결과 / 5장 CTA
- 예 ([브랜드명]):
  - 1장 "잡티가 더 진해진 30대"
  - 2장 "비싼 앰플도 효과가 없었어요"
  - 3장 "4주째 거울을 보고 놀랐어요"
  - 4장 "광채 임상 84% 결과"
  - 5장 "1+1 시크릿 특가 →"

### 골격 ③ — 리스트형 (Listicle)

```
[N가지 ___ 후킹] → [항목 1~N-2 슬라이드] → [요약·CTA]
```

- 적합: 팁·체크리스트·랭킹·"~하는 N가지" / 저장 유도 콘텐츠 디폴트
- 5장 매핑: 1장 "광채 망치는 3가지" / 2장 항목 1 / 3장 항목 2 / 4장 항목 3 / 5장 저장 CTA
- 예 ([브랜드명]):
  - 1장 "광채 망치는 3가지 습관"
  - 2장 "① 각질 안 정리"
  - 3장 "② 진정만 하고 끝"
  - 4장 "③ 28일 기다리기"
  - 5장 "저장하고 4주 챌린지 시작 →"

## 2. 슬라이드 수별 아크 분배

| 슬라이드 수 | Hook | 본문 | CTA | 비고 |
|---|---|---|---|---|
| 3장 (min) | 1장 | 1장 | 1장 | 인포그래픽·단순 메시지 |
| **5장 (디폴트)** | **1장** | **3장** | **1장** | 균형형 |
| 7장 | 1장 | 5장 | 1장 | 깊이 있는 정보 |
| 10장 (max) | 1장 | 8장 | 1장 | 시리즈·교육 콘텐츠 |

> 10장 초과는 IG 카루셀 한도(10장)도 초과. 분할 시리즈로 안내.

---

## 3. 골격 선택 매핑 (인풋 → 골격)

분기 B 자동 도출 시 사용자 토픽 + 페인·USP 조합으로 매핑:

| 사용자 토픽·인풋 시그널 | 추천 골격 | 이유 |
|---|---|---|
| "성분 소개", "이 성분이 왜 중요한가" | ① 정보형 | 교육 의도 |
| "고객 후기", "비포애프터", "한 명의 이야기" | ② 스토리형 | 감정 공감 |
| "~하는 N가지", "체크리스트", "랭킹", "팁" | ③ 리스트형 | 저장·공유 친화 |
| pain_points Top 페인이 명확 + 솔루션 흐름 | ② 스토리형 | 페인 공감 후 반전 |
| brand_brief USP 가 임상수치·랭킹 중심 | ① 정보형 | 신뢰 구축 |
| 알고리즘 노출용 일반 콘텐츠 | ③ 리스트형 | 저장률 ↑ |

사용자가 "리스트형으로" / "스토리로 가자" 등 명시 시 override.

---

## 4. 슬라이드별 1줄 시나리오 도출 절차 (분기 B)

1. **골격 선택** (위 표) — 1개 확정
2. **Hook 슬라이드 1줄** — `text-density-caps.md` Hook 캡 (≤8단어·≤15자) 준수. pain_points 페인 인용 또는 brand_brief USP 인용
3. **본문 슬라이드 N-2 줄** — 골격 단계별 1줄씩. 각 슬라이드 1메시지 룰. `text-density-caps.md` 본문 캡(≤30자×2줄)
4. **CTA 슬라이드 1줄** — `carousel-cta-library.md` 6종 풀에서 1개. 직접 가격 ❌
5. **검수·치환**:
   - `banned-words.md` — "비드" → "캡슐" 등 한글 카피 치환
   - `text-density-caps.md` — 자수 캡 초과 시 토큰 단위 압축
6. **출처 기록 (in-memory)** — 1장 슬라이드별 (인풋 출처 = pain_points #N / USP #M / 경쟁사 빈틈 K)

결과는 in-memory 변수. NanoBanana 프롬프트 [4] TEXT EFFECT 블록 큰따옴표 인용 + v1 보고 시 채팅 동봉.
