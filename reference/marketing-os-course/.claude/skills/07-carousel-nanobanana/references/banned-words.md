> 본 파일은 07-carousel-nanobanana 스킬이 슬라이드 텍스트 도출 후 NanoBanana 호출 직전 **자동 검수·치환** 한다. 슬라이드별 한글 헤드·본문·CTA 가 검수 대상. 영문 매크로 어휘 (NanoBanana 프롬프트 영문 묘사) 는 별도.
>
> 출처: 05-ad-image-nanobanana 의 `references/banned-words.md` 를 카드뉴스 콘텍스트에 맞게 조정.

## 카테고리별 금지 단어

### 1. 제형 묘사 (영문식 표현)

| ❌ 금지 | ✅ 대안 | 비고 |
|--------|--------|------|
| 비드 / 캡슐 비드 | **캡슐**, **톡 터지는 캡슐**, **캡슐 알갱이** | 영문식 어색. 단순 "캡슐"로 충분. |

> ⚠️ NanoBanana 프롬프트 영문 매크로 ([2] PRODUCT / [3] EFFECT) 에서는 `capsule beads`·`small round beads` 허용. **한글 슬라이드 텍스트** (TEXT EFFECT 큰따옴표 인용) 에는 ❌.

### 2. CTA 슬라이드·시각 영역

| ❌ 금지 | ✅ 대안 | 비고 |
|--------|--------|------|
| **직접 가격 노출** (`28,900원`·`회원가 19,800원`) | `carousel-cta-library.md` 6종 풀에서 1개 | CTA 슬라이드 시각 영역 ❌. IG 캡션 본문 (별도 산출물) 에는 OK |
| **% OFF 직접 노출** (`35% OFF`) | "시크릿 가격 →", "런칭 한정 →" | 시각 영역 ❌. 본문에서만 |
| **번들 직접 표기** (`1+1`, `2+1`) | "함께 받는 시크릿 세트" | 시각 영역 ❌. 본문에서만 |

> 오가닉 SNS 콘텐츠는 가격 직접 노출 시 도달률 ↓ + 광고 표시 의무 리스크. 가격은 캡션 본문에.

### 3. 의약품 연상·과장 단정

| ❌ 금지 | ✅ 대안 | 비고 |
|--------|--------|------|
| "치료 / 완치 / 효능" | "케어 / 진정 / 결과" | 화장품법 의약품 연상 표현 ❌ |
| "100% / 무조건 / 절대" | "임상 N% (출처)", "X일 만에" | 과장 단정 ❌. 출처 표기 의무 |
| "기적 / 마법 / 신세계" | 페인 인용 + 결과 수치 | 객관 근거 우선 |

### 4. 톤 / 어미 (카드뉴스 특화)

| ❌ 금지 | ✅ 대안 | 비고 |
|--------|--------|------|
| `~합니다 / ~입니다` (과한 격식) | `~다 / ~죠 / ~네요` 또는 명사 종결 | SNS 톤 — 친근·일상 |
| "여러분~", "고객님~" (과한 호명) | "당신", 호명 생략 | 거리감 ↓ |

### 5. (예약) brand_brief Never 표현

> `01_brand/brand_brief.md` § Never 표현 절을 본 파일에 동적 인용. 브랜드별 다름.

## 검수 절차 (★ 07 스킬에서 자동)

NanoBanana 호출 직전:

1. 슬라이드별 한글 헤드·본문·CTA 텍스트
2. NanoBanana 프롬프트 [4] TEXT EFFECT 블록 큰따옴표 한글 인용
3. 자 위 / 슬라이드 위 시각 마커 한글 라벨

위 3곳에서 본 파일의 ❌ 단어가 발견되면 **호출 직전 자동 교체**. 사용자에게 별도 보고 ❌. v1 출력 보고의 슬라이드 시나리오 동봉부에는 치환 후 텍스트 노출 → 사용자 결과 보고 자연 검수.

## 신규 단어 추가 시

사용자가 "X 단어 쓰지 말아줘", "Y 표현은 금지" 같은 룰성 피드백을 주면:

1. 카테고리 식별 (제형 / CTA / 의약품·과장 / 톤 / 기타)
2. 본 파일의 해당 카테고리 표에 ❌ 단어 + ✅ 대안 추가
3. 05-ad-image-nanobanana 의 `banned-words.md` 와 공유해야 하는 룰이면 그쪽도 동기화 (제형·의약품 카테고리는 보통 공유)
4. SKILL.md CHANGELOG (있으면) 갱신
5. 현재 작업 중인 시안은 v 증가하며 치환
