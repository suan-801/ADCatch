# 04. 브리프 합성 (단계별 오케스트레이터, v3)

> 2-1·2-2·2-3 분석 → **메시지 1개 선택 → 1차 시안 → 컨펌 → 1차 이미지 → 6종 변형 → 선택 → 추가 이미지** 의 5 스텝 인터랙티브 흐름.

## 언제 호출되는가

- "브리프 만들어줘"
- "광고 컨셉 도출해줘"
- "스토리보드 만들어줘"
- "/04-brief-synthesizer"

---

## Prerequisites

- **★ 필수** — `01_brand/brand_brief.md` (없으면 → "`/01-brand-from-url <URL>` 로 자사 분석을 먼저 해주세요" 안내 후 **종료**). 메시지 후보·USP·톤·컬러의 본체라 누락 시 합성 불가능.
- **권장** — `02_competitor/competitor_ads.md` (없으면 → 경고 후 **약식 진행**. 차별화 빈틈 판단이 빠지므로 산출물에 `(경쟁사 자료 없음 — 약식 분석)` 라벨 명시)
- **권장** — `03_customer/pain_points.md` (없으면 → 경고 후 **약식 진행**. Hook 후킹 키워드와 F 리뷰형 앵글 정밀도가 떨어지므로 산출물에 `(고객 분석 없음 — 약식 분석)` 라벨 명시)

> 💡 자사 분석만 끝나도 04 호출 가능. 단 권장 인풋 누락 시 산출물 정확도가 떨어지므로, 본격 캠페인 전엔 02·03 모두 보강 권장.

## 5 Step 흐름 (★ 본 스킬의 핵심)

```
[Step 0] 인풋 검증 (자사 필수 / 경쟁사·고객 권장)
   ↓
[Step 1] 메시지 3개 추천 (가능 축만 합성)
   └─ 컨펌 게이트 ① : User "1번" or "당근 23%"
   ↓
[Step 2] 1차 4섹션 스토리보드 (기본 Hero)
   └─ 컨펌 게이트 ② : User "컨펌" or "User's Pain Point 더 짧게"
   ↓
[Step 3] /05 자동 호출 → 1차 이미지
   ↓
[Step 4] 6종 변형 스토리보드 자동 제안
   └─ 컨펌 게이트 ③ : User "A, C, F" or "F 리뷰형만"
   ↓
[Step 5] 선택 N개 → /05 N회 자동 호출
   ↓
종료 (총 1+N장 이미지)
```

### Step 0. 인풋 검증

- **자사** `01_brand/brand_brief.md` — 없거나 비어있으면 → Prerequisites 안내 후 **종료** (강제 게이트)
- **경쟁사** `02_competitor/competitor_ads.md` — 없거나 비어있으면 → 채팅에 경고 1줄 ("⚠️ 경쟁사 분석 없이 약식 진행합니다. 차별화 빈틈 판단이 빠지므로 `/02-competitor-from-adlib` 호출 권장.") + 산출물에 `(경쟁사 자료 없음 — 약식 분석)` 라벨 명시 + 진행
- **고객** `03_customer/pain_points.md` — 없거나 비어있으면 → 채팅에 경고 1줄 + 산출물에 `(고객 분석 없음 — 약식 분석)` 라벨 명시 + 진행
- 누락 축은 이후 단계에서 폴백 로직으로 처리 (아래 Step 1·4 참조)

### Step 1. 메시지 3개 추천 → 1개 선택

- 소스: `brand_brief.md § USP A 시그니처 3종` 자동 추출 (부족 시 § C 마케팅 카피 USP 에서 보강)
- **누락 축 폴백**:
  - `competitor_ads.md` 없음 → 차별화 빈틈 우선순위 적용 ❌, brand_brief USP 단독 기반. 메시지 옆에 `(경쟁사 미반영)` 작은 라벨 표기.
  - `pain_points.md` 없음 → Hook 후킹 키워드(페인·욕구) 적용 ❌, brand_brief § 타깃·톤 만으로 메시지 채택.
- 채팅 출력:
  > "다음 3 메시지 중 1개 골라주세요:
  > 1. {USP A1} ({분류})
  > 2. {USP A2}
  > 3. {USP A3}
  > → '1번' 또는 '{메시지명}' 자연어 입력"
- **컨펌 게이트 ①** : 사용자 1개 선택까지 대기

### Step 2. 1차 4섹션 스토리보드 (기본 Hero)

- 선택 메시지 + 기본 Hero 앵글로 4섹션 1세트 생성
- 기본 Hero 정의 = 메시지 약속 + `brand_brief § RTB` 1줄 (정공법, 다른 앵글 변형 ❌)
- `04_brief/confirmed_brief.md` 저장 (§ 1 컨셉 / § 2 메시지 후보·선택 / § 3 1차 4섹션)
- 채팅 출력: § 3 4섹션 표 동봉 + 컨펌 요청
- **컨펌 게이트 ②** : 사용자 "컨펌" 또는 수정 요청 ("User's Pain Point 더 짧게" 등 자연어 → v2 재도출)

### Step 3. /05 자동 호출 → 1차 이미지

- 사용자 "컨펌" → 04 가 즉시 `/05-ad-image-nanobanana` 호출
- 인풋: `confirmed_brief.md § 3` 의 4섹션
- 파일명: `{브랜드}_{메시지슬러그}_meta-feed_conceptHero-v1.png`
- **★ NanoBanana 호출 시 reference 이미지 필수 첨부** (재발 방지):
  - `01_brand/logos/*.png` 에서 로고 1장
  - `01_brand/products/main-angles/*.png` 에서 제품 정면·드로퍼 1~2장
  - 시안 톤에 맞춰 `01_brand/products/studio/*.png` 또는 `lifestyle/*.png` 1장 추가
  - reference 없이 텍스트 프롬프트만 호출 ❌ — 비주얼 일관성·브랜드 자산 활용 실패 사유
- 완성 후 채팅 동봉, § 5 제작 이력 갱신

### Step 4. 6종 변형 스토리보드 자동 제안

1차 이미지 완성 직후 04 가 자동으로 6종 변형 스토리보드 1세트 생성. 동일 메시지 × 6 앵글 (Hero 제외).

> **★ 레이아웃 다양화 의무 (2026-05-25 도입)** — 시각 시그니처(컬러 6슬롯 · ④ Promotion 박스 색·폰트 페어링)는 6종 전체에서 **유지**. 그러나 **레이아웃·구도·제품 위치·헤드 위치**는 매번 **반드시 다르게**. Hero v2 의 룩앤필을 6장 그대로 복제하면 광고 피드에서 같은 광고로 인식돼 피로도 ↑ — 같은 폴더에서 6장 동시 비교 시 즉시 식별 가능해야 함. K-뷰티 실전 (경쟁사 A·B·C) 표준 = "시그니처 일관, 레이아웃 변주".
>
> **★ 미니멀 디폴트 룰** — 시각 영역 정보 밀도 = LOW. 한 시안에 텍스트 요소 ≤5개. **4종 인증 뱃지 좌하단 2×2 그리드는 디폴트 ❌** — 뱃지 가득 채우면 정보 과부하로 광채·제품이 묻힘. 인증·신뢰 자산은 시안 컨셉이 그것일 때만 1~2개 선택 노출:
> - **인증 가시화 ❌** (디폴트 — 미니멀): Hero · A 할인 · B 성분 · C 번들 → **USP 강조 뱃지 1개만** (예: "23% 농축" / "임산부 가능")
> - **인증 가시화 ✅** (1~2개 선택): D 사회증거 · E 비포애프터 · F 리뷰형 → 캠페인 메시지가 신뢰·인증 핵심이라 1~2개 노출 OK (전체 4종 ❌, 캠페인 정합 1~2개만)
>
> 사용자가 "4종 다 노출" 명시 요청 시만 4종 풀세트.

| B | 성분 히어로 (#16) | Solution 이 성분명·농도 자체 | **원물 매크로 풀블리드** — 원재료(당근·꽃·열매)가 화면 절반 이상 점유. 제품은 우측 인서트. 성분 아이콘 그리드 보조 | brand_brief § USP A |

> 6 시안 옆에 두고 봤을 때 **레이아웃만으로 즉시 어느 앵글인지 식별 가능**해야 변주 성공. 헤드 위치·제품 위치·메인 시각 요소가 6장 모두 다르면 OK. 시그니처(컬러·뱃지 색·④ 박스 색·폰트)는 다르면 ❌ (브랜드 인지 약화).

- `confirmed_brief.md § 4` 에 6종 표 누적 추가 (각 셀 4섹션 1줄씩 압축 + ★ 레이아웃 패턴 1줄 명시)
- 채팅 출력:
  > "다음 6종 중 추가로 만들 시안을 골라주세요:
  > 'A 할인' / 'B 성분' / 'C 번들' / 'D 사회증거' / 'E 비포애프터' / 'F 리뷰형'
  > 여러 개 선택 가능: 'A, C, F'"
- **컨펌 게이트 ③** : 사용자 선택 입력 대기 (0개 = 종료 / N개 = Step 5 진입)

### Step 5. 선택 N개 → /05 N회 자동 호출

- 선택된 각 앵글마다 `/05-ad-image-nanobanana` 순차 호출
- 파일명: `{브랜드}_{메시지슬러그}_meta-feed_concept{앵글ID}-v1.png`
  - 앵글ID: Discount / Ingredient / Bundle / Proof / BeforeAfter / Review
- 각 이미지 완성 시 채팅 동봉, § 5 제작 이력 갱신
- 모두 완료 후:
  > "총 (1+N)종 이미지 완성. 추가 변형이나 수정은 자연어로 요청해주세요."

- **Solution 은 짧은 약속 1줄** (brand_brief 의 마케팅 카피 USP 결). 임상 수치는 § 4 Visual 뱃지로 분리
- **★ Promotion 은 짧은 임팩트 — 디폴트 자수 ≤12자 (혜택 최대 2개)**. 02 경쟁사 평균 8~13자 (`copy-char-caps.md § 3-1` 실측표). 3개 이상 욱여넣기 ❌ — 시선 분산. 02 경쟁사 광고 패턴 참고: "0원!" (3자) / "오늘의 특가 44%" (8자) / "30% OFF 면봉 증정" (10자) / "1+1 마지막 특가" (8자) 처럼 **숫자 1개 + 사은품 또는 시급성 1개** 로 압축.
- **★ Promotion 강제 분리 룰** (의무): 환불·배송·임상 안전 안내 (예: "30일 환불 보장", "무료배송", "임상 28명") 는 ④ Promotion 에서 **반드시 분리** → ② Solution RTB 슬롯 또는 ③ Creative Key Visual 인증 뱃지로 이동. Promotion 카피에 남기면 시선이 분산되고 행동 압력이 약해짐.
- **Promotion 혜택 우선순위** (1~2개만 채택): ① 가격 수치 (N% / N원 / 0원) ≫ ② 사은품·증정 (미니어처·1+1) ≫ ③ 시급성 (단 N일·런칭·채널 한정) ≫ ④ 신뢰 (환불·배송) — ④ 는 ④ Promotion 박스 ❌, 인증 뱃지로 분리
- **★ 텍스트 중복 금지** (★ 2026-05-25 신설) — 한 시안 안에 같은 핵심 단어·숫자 **최대 2회, 권장 1회**. 헤드 + USP 뱃지 + ④ 박스에 `-20%` / `1+1` / `농가` 같은 키워드가 3번 등장 ❌. 영역별로 **다른 정보 차원**을 담당 (① 페인 / ② 약속+RTB / ③ 큰 숫자 1포인트 / ③ USP 뱃지 다른 USP / ④ 혜택 명사 / ④ CTA 동사). 자세한 룰은 `copy-char-caps.md § 4`.
- **★ 할인율 부호 표기** (★ 2026-05-25 신설) — 할인율에 `-` 부호 ❌. `-20%` → **`20%`** 또는 **`20% OFF`**. K-뷰티 광고 표준 (02 경쟁사 4사 모두 `-` 부호 사용 ❌). 가격 비교 시 정가→할인가 화살표 (`₩48,000 → ₩38,400`) 는 OK.
- **6 앵글은 메시지 약속 공유** — 같은 메시지의 6 앵글에 "당근 23%" 같은 USP 키워드가 어딘가에 등장
- **F 리뷰형은 실제 리뷰 1줄 인용** — `pain_points.md § 1` 또는 `03_customer/reviews/` 원본에서 메시지 키워드가 나오는 발췌

❌ 금지
- 의약품 단정 어휘 ("100% 효과", "치료") → 의문문 변환
- 경쟁사명 직접 비방 → "5만원대 광채 세럼" 같은 일반화
- **자사도 가진 페인** (pain_points § 6 자기 발등) 을 User's Pain Point 로 사용 ❌
- User's Pain Point · Solution · Promotion 각 줄에 정보 2개 이상 욱여넣기 ❌
- F 리뷰형의 리뷰 발췌를 임의 창작 ❌ — 반드시 원본 인용
