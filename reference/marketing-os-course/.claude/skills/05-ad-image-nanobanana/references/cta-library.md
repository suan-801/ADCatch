# CTA 라이브러리 — 호기심 유발형 5종 (★ ④ Promotion 안의 CTA 의무)

> 본 파일은 04-brief-synthesizer / 05-ad-image-nanobanana 스킬의 **④ Promotion 슬롯 안에 흡수된 CTA (USP 4축 ① Pain Point · ② Solution · ③ Creative Key Visual · ④ Promotion(+CTA) 중 ④)** 도출 단계에서 사용한다. **Promotion 박스 안의 CTA 풀바·버튼 시각 영역에 직접 가격 노출 ❌** — 호기심 유발형 5종 라이브러리 중 1개 선택.

---

## 1. 호기심 유발형 CTA 5종 (라이브러리)

시안마다 1개 선택. 시안 컨셉·골격·번들 여부에 맞춰 매칭:

| # | CTA | 적합 골격 | 적합 시점 |
|---|-----|----------|----------|
| 1 | `이 링크에서만 받는 시크릿 특가 ›` | A · B · C | 디폴트 (가장 보편) |
| 2 | `런칭 기념 회원 시크릿 특가 ›` | D · E | 신제품 런칭·한정 |
| 3 | `1+1 특가 — 이 링크에서만 ›` | B · C | 번들 강조 |
| 4 | `회원만 받는 시크릿 가격 ›` | A · C | 회원·구독 푸시 |
| 5 | `오늘만 시크릿 할인 ›` | A · D | FOMO·긴급 |

---

## 2. 금지 패턴

### ❌ 직접 가격 노출

CTA 풀바·자 위 시각 마커·헤드라인 시각 영역에서:

- `28,900원` / `19,800원` / `회원가 28,900원` 같은 숫자 ❌
- `35% OFF` / `50% 할인` 같은 % 직접 노출 ❌

> 예외: ② Solution 내 RTB 블록 텍스트 (메타 광고 캡션 본문) 에서는 임상 % 인용 OK. 본 라이브러리는 **시각 영역**의 CTA 풀바·뱃지 한정 (④ Promotion 박스 안).

### ❌ "구매하기" / "지금 구매" 직접 명령형

K-뷰티 표준은 호기심·시크릿 키워드로 클릭 유도. 직접 명령형은 푸시 광고에 가까워 톤 충돌.

---

## 3. 디폴트 매칭 룰

골격이 정해지면 디폴트 CTA:

- **골격 A** (임상 + 1위 + 할인) → `이 링크에서만 받는 시크릿 특가`
- **골격 B** (페인 + 솔루션) → `이 링크에서만 받는 시크릿 특가`
- **골격 C** (망설임 격파) → `회원만 받는 시크릿 가격`
- **골격 D** (호기심 후크) → `런칭 기념 회원 시크릿 특가` 또는 `오늘만 시크릿 할인`
- **골격 E** (성분 해시태그) → `런칭 기념 회원 시크릿 특가`

번들·세트 시안은 골격 무관 `1+1 특가 — 이 링크에서만` 우선 적용.
