# 카피 자수 캡 (★ K-뷰티 표준 토큰화)

> 본 파일은 05-ad-image-nanobanana 스킬이 카피 도출 후 자수를 압축할 때 적용하는 캡 룰. **시각 영역에 들어가는 한글 카피는 토큰 단위로 끊는다 — 문장체 ❌**.

---

## 1. 자수 캡 (의무)

> ③ Creative Key Visual 은 비주얼 시드 (자수 캡 ❌). 자수 캡은 ①·②·④ 카피 슬롯만 적용.

### 1-1. USP 4축 자수 캡 (마스터)

| 축 | 라벨 | 자수 캡 | 예시 |
|---|---|---|---|
| ① | **User's Pain Point** | ≤15자 | `"거울 앞 죽어 보이는 안색"` (의문문 변환 우선) |
| ② | **Solution** | ≤26자 (≤13자 × 2줄) | `수분 한 방울 광채 세럼 / 고농축 · 4종 핵심 성분` (USP 약속 1줄 + RTB 1줄) |
| ③ | **Creative Key Visual** | 비주얼 시드 — 자수 캡 ❌ | (제품·구도·뱃지·라이팅 묘사. 텍스트 카피 ❌) |
| ④ | **Promotion (+ CTA)** | ≤22자 (혜택 ≤12자 + CTA ≤10자) — **혜택 최대 2개**. 환불·배송·신뢰는 ② RTB 슬롯으로 분리 | `런칭 20% · 미니어처 10ml / 시크릿 가격 ›` (`cta-library.md` 호기심 유발형 5종) |

### 1-2. 시각 영역 슬롯 (디자인 매핑)

| 슬롯 | 4축 매핑 | 자수 캡 | 설명 |
|------|---|--------|------|
| **인용 후킹** (작은 따옴표) | ① User's Pain Point | **≤15자** | 시안 상단 인용 |
| **카테고리 약속** (중간) | ② Solution 내 USP 약속 | **≤10자** | 시각 중심 강조 |
| **메인 헤드라인** (가장 큼) | ② Solution USP 약속 1줄 | **≤12자 × 2줄** | 토큰 단위 줄바꿈. 예: `수분 한 방울로 / 광채가 시작돼요` |
| **메인 헤드라인 sub** | ② Solution 내 RTB 부가 | **≤12자** | 헤드 아래 1줄 |
| **큰 숫자 강조** | ② Solution 내 임상 % | 숫자 + 단위 (예: `30%`, `5초`, `230배`) | 1포인트 컬러 (`BRAND-Signature`) |
| **해시태그** (4개) | 시각 적층 보충 (③) | 각 ≤10자 | K-뷰티 5앵글 적층 분배 |
| **프로모션 뱃지** | ④ Promotion 혜택 | **≤12자** (혜택 최대 2개) | "런칭 20% OFF", "미니어처 증정", "신규 추가 10%" 등 — 02 경쟁사 평균 8~13자 (CTA 풀바와 같은 박스 안) |
| **CTA 풀바** | ④ Promotion 내 CTA | ≤20자 | 호기심 유발형 (`cta-library.md`) — Promotion 박스 안에 흡수 |
| **USP 강조 뱃지** (★ 미니멀 디폴트 — 시안당 1개만) | ② Solution 내 핵심 USP 1개 | ≤8자 | 예: "고농축", "빠른 흡수", "민감성 가능", "산지 직배". 시안 컨셉별 1개만 (다중 ❌) |
| **인증 뱃지** (옵션 — 캠페인 신뢰 강조 시만) | ③ Creative Key Visual 신뢰 자산 | ≤8자/뱃지, 최대 2개 | "EWG 그린", "V-Label Vegan", "30일 환불", "무료배송" 4종 중 캠페인 정합 1~2개만. 4종 풀세트 2×2 그리드 ❌ (디폴트). 사용자 명시 요청 시만 풀세트 |
| **이미지 셀 라벨 (cap)** | 시각 마커 (③) | ≤8자 | 자 위 시각 마커 (예: `빠른 흡수`, `고농축`, `산지 직배`) |

## 2. 토큰 단위 끊기 (★ 문장체 ❌)

K-뷰티 광고는 **한 줄에 한 호흡씩** — 문장체로 흘리면 시각적으로 길어 보이고 압축 ❌.

### 토큰 분리 패턴

| 패턴 | ✅ 토큰화 | ❌ 문장체 |
|------|----------|----------|
| 페인 + 솔루션 | `끈적임 NO,` / `한 방울로 충분해요` | `끈적임 NO, 한 방울이면 충분히 광채가 나요` |
| 성분 + 결과 | `수분 한 방울로` / `바르면 광채 시작` | `수분 한 방울로 바르는 즉시 광채가 시작되는 피부` |
| 페인 묘사 | `죽어 보이는 안색,` / `수분 한 방울로` | `죽어 보이는 안색을 수분 한 방울로 살려줍니다` |

> 디폴트 검증 사례: 시안 v1 이 문장체로 흘러 K-뷰티 표준 대비 길어 보임 → 토큰 단위 끊기로 압축.

### 줄바꿈 위치 (의무)

- **쉼표 위치**: 토큰 끝 (예: `끈적임 NO,` 줄바꿈)
- **조사 끊기 ❌**: 조사로 끝나는 줄바꿈 (예: `수분 한 방울` 다음 줄 `로 바로`) → 부자연
- **숫자·단위는 한 토큰**: `5초` / `30%` / `230배` 는 줄바꿈 ❌

## 3. 압축 절차 (★ 05 스킬에서 자동)

1차 카피 후보 (`copy-4-axis-framework.md § 3`) 가 자수 캡을 초과하면:

1. **불필요 어미 제거** (`~합니다` → `~해요` / `~이에요` 또는 명사형 종결)
2. **중복 토큰 제거** (`광채 시작되는 피부 광채` → `광채가 시작돼요`)
3. **조사 압축** (`~를 위한` → 명사 직결)
4. **숫자·단위 우선** (수치는 줄임 ❌)

압축 후에도 캡 초과 시 → 골격 변경 (예: 골격 B → C 로 망설임 격파 패턴)

### 3-1. ④ Promotion 전용 압축 룰 (★ 의무 — 02 경쟁사 평균 8~13자 기준)

자수 초과 외에 **혜택 개수 초과** 시도 강제 압축. K-뷰티 경쟁사 실전 패턴 기준:

| 02 경쟁사 실측 예시 | 자수 | 패턴 |
|---|---|---|
| `0원!` | 3자 | 단일 숫자 임팩트 |
| `오늘의 특가 44%` | 8자 | 시급성 1 + 할인율 1 |
| `30% OFF 면봉 증정` | 10자 | 할인율 1 + 사은품 1 |
| `공식몰 단독 10% OFF` | 10자 | 채널 한정 1 + 할인율 1 |
| `1+1 마지막 특가 37,900원` | 13자 | 1+1 + 시급성 + 원가 |
| `오직 채널 단독 1+1 55% OFF` | 15자 | 채널 한정 + 1+1 + 할인율 (최대 권장) |

**압축 강제 룰**:

1. **혜택 ≥ 3개면 무조건 압축** → 가장 임팩트 큰 1~2개만 남김. 우선순위: ① 가격 수치 (`N%` · `N원` · `0원`) ≫ ② 사은품·증정 (`1+1` · `미니어처`) ≫ ③ 시급성 (`단 N일` · `런칭` · `채널 한정`) ≫ ④ 신뢰 (환불·배송)
2. **환불·배송·임상 안전 안내** (예: "30일 환불 보장", "무료배송", "임상 N명") 은 ④ Promotion 에서 **반드시 분리** → ② Solution RTB 슬롯 또는 ③ Creative Key Visual 인증 뱃지로 이동
3. **연결사 압축** — `런칭 20% · 미니어처 10ml 증정 · 30일 환불 보장` (22자) → `런칭 20% · 미니어처` (10자) 로 토큰 단위 끊기. 단위·수량 (`10ml`, `5매`) 도 시급성 ❌ 면 생략
4. **혜택 2개 권장 패턴**: `[숫자/할인] · [사은품 또는 시급성]` (예: "런칭 20% · 미니어처" / "1+1 · 단 7일") — 3개 이상 ❌

### 3-2. ④ Promotion 잘못된 예시 vs 압축 후

| ❌ 욱여넣기 (긴 경우) | 자수 | ✅ 압축 후 | 자수 |
|---|---|---|---|
| `런칭 20% · 미니어처 10ml 증정 · 30일 환불 보장` | 22 | `런칭 20% · 미니어처` | 9 |
| `오늘 가입 시 1+1 + 무료 배송 + 첫구매 5천원 할인` | 22 | `1+1 · 첫구매 5천원` | 10 |
| `35% OFF + 미니어처 증정 + 30일 환불 + 무료배송` | 23 | `35% OFF · 미니어처` | 10 |
| `5월 한정 30% 할인 · 면봉 증정 · 30일 환불` | 19 | `5월 한정 30% · 면봉` | 11 |

압축으로 빠진 안전 자산 (환불·배송) 은 시각 영역의 **인증 뱃지 슬롯** (③ Creative Key Visual) 으로 분리 노출 — `[30일 환불]` `[무료배송]` 작은 원형 뱃지.

## 4. 텍스트 중복 검수 룰

> ⚠️ **한 시안 안에 같은 메시지/핵심 단어 반복 ❌** — 헤드라인 + USP 뱃지 + ④ Promotion 박스에 같은 `-20%` / `1+1` / `단독` 같은 키워드가 2~3번 들어가면 시각 영역이 지저분해지고 임팩트 ↓. 광고는 "한 번에 강하게" 가 원칙.

### 4-1. 핵심 단어·숫자 중복 한도

| 단어·요소 | 한 시안 내 최대 등장 횟수 | 권장 |
|---|---|---|
| 할인율 숫자 (`20%`, `25%`, `30%` 등 — `-` 부호 ❌, § 4-4 참조) | **최대 2회** | 1회 권장 |
| 가격 숫자 (`₩38,400`, `₩48,000`) | **최대 2회** | 1회 권장 (정가+할인가 한 쌍은 1회로 카운트) |
| 핵심 키워드 (`성분`, `민감성`, `고농축`, `흡수`) | **최대 2회** | 1회 권장 |
| 캠페인 USP 메시지 (`한 방울로 충분`, `빠른 흡수`) | **최대 2회** | 1회 권장 |
| 호기심 후크 어휘 (`시크릿가`, `놓치셨어요?`) | **최대 1회** | 1회만 |

### 4-2. 잘못된 중복 예시 → 압축 후

| ❌ 중복 패턴 | 어떤 영역에 같은 단어가 등장? | ✅ 압축 후 |
|---|---|---|
| 헤드 "단독 20%, 놓치셨어요?" + 거대 "20%" + ④ 박스 "단독 20% · 미니어처" | `20%` 3회, `단독` 3회 | 헤드 "공식몰 단독 놓치셨어요?" → 거대 "20% OFF" → ④ 박스 "· 미니어처 · 시크릿가 ›" |
| 헤드 "한 방울로 충분해요" + 우측 뱃지 "한 방울 충분" + ④ 박스 "한 방울 광채 20%" | `한 방울` 3회 | 헤드 "한 방울로 충분해요" → 뱃지 "빠른 흡수" → ④ 박스 "런칭 20% · 미니어처 ›" |
| 헤드 "성분 30%, 어디서 농축?" + 거대 "30%" + ④ 박스 "30% 농축 보기 ›" | `30%` 3회 | 헤드 "어디서 온 성분이죠?" → 거대 "30%" → ④ 박스 "공식몰 단독 · 시크릿가 ›" |

### 4-3. 영역별 메시지 분담 룰 (의무)

각 영역은 **다른 정보 차원** 으로 채움 — 같은 정보 반복 ❌:

| 영역 | 담당 정보 차원 | 예시 |
|---|---|---|
| ① User's Pain Point (헤드) | **페인 후킹** — 의문문·감탄 | "산지 직배 놓치셨어요?" |
| ② Solution 약속·RTB | **약속 + 임상·인증** | "산지 직배 · 12시간 이내" |
| ③ Creative Key Visual 큰 숫자 | **시각 임팩트 1포인트** — 할인율 OR USP 수치 OR 임상 % | "20% OFF" 또는 "30%" 또는 "84%" |
| ③ USP 강조 뱃지 1개 | **시각 강조 1포인트** — 시각 영역에 들어가지 않은 다른 USP 1개 | "산지 직배" (다른 차원) |
| ④ Promotion 혜택 | **혜택 명사** — 사은품·번들 명사 | "미니어처" / "듀오" |
| ④ CTA | **호기심 동사** — "보기"·"확인"·"시작" | "시크릿가 ›" |

→ 헤드에 "산지" 가 들어갔으면 ③ 큰 숫자나 USP 뱃지에서는 "산지" 빼고 **다른 USP** (예: "고농축") 노출. ④ 박스도 "산지" 빼고 "미니어처 · 시크릿가" 처럼 정보 다르게.

### 4-4. 할인율 부호 표기 룰

> ⚠️ **할인율에 `-` 마이너스 부호 ❌** — "-20%" 가 아니라 **"20%"** 또는 **"20% OFF"**.

| ❌ 잘못된 표기 | ✅ 올바른 표기 |
|---|---|
| `-20%` | `20%` 또는 `20% OFF` |
| `-25%` | `25%` 또는 `25% OFF` |
| `-30% 할인` | `30% 할인` |
| `런칭 -20%` | `런칭 20%` |

**이유**: 한국 K-뷰티 광고 표준은 "30% OFF" / "25% 할인" / "20% SALE" 형식 (02 경쟁사 실측 — 경쟁사 A·B·C·D 모두 `-` 부호 사용 ❌). `-` 부호는 회계·수학 어감이라 광고 톤에 안 맞음.

**예외**: 가격 비교 시 정가 → 할인가 화살표 그래픽으로 표현 (`₩48,000 → ₩38,400`). 강조용 ` - ` (구분자) 는 OK.

## 5. 폰트 크기 매핑 (1080×1080 환산, NanoBanana 출력 기준)

| 요소 | 자수 캡 | 1080 환산 (~px) | 비고 |
|------|--------|----------------|------|
| 인용 후킹 | ≤15자 | ~30px | line-height 1.4 |
| 카테고리 약속 | ≤10자 | ~54px | font-weight 800, line-height 1.2 |
| 메인 헤드라인 | ≤12자 × 2줄 | ~95~120px | font-weight 900, line-height 0.95~1.05 |
| 큰 숫자 강조 | (숫자 + 단위) | ~165px | line-height 0.85, BRAND-Signature 컬러 |
| 해시태그 (4개) | 각 ≤10자 | ~28px | font-weight 700 |
| CTA 풀바 | ≤20자 | ~34px | font-weight 700 |
| 이미지 셀 라벨 | ≤8자 | ~15px | rgba 흰배경 배지 |

> 이 비율은 1:1 박스 안에 헤드카피·이미지·해시태그·CTA 가 압축 없이 들어가도록 검증된 표준값. NanoBanana 프롬프트 [4] TEXT EFFECT 블록에서 폰트 사이즈를 지정할 때 참고.
