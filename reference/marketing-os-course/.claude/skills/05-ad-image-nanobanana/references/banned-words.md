## 검수 절차 (★ 05 스킬에서 자동)

NanoBanana 호출 직전:

1. USP 4축 (① User's Pain Point · ② Solution · ④ Promotion(+CTA) 한글 텍스트 — ③ Creative Key Visual 은 비주얼 시드라 검수 대상 ❌)
2. NanoBanana 프롬프트 [4] TEXT EFFECT 블록 큰따옴표 한글 인용
3. 자 위 시각 마커 한글 라벨
4. 해시태그 4개

위 4곳에서 본 파일의 ❌ 단어가 발견되면 **호출 직전 자동 교체**. 사용자에게 별도 보고 ❌ (룰 적용은 자동, 다만 v1 출력 보고의 USP 4축 동봉부에는 치환 후 카피 그대로 노출 — 사용자가 결과 보고 자연 검수).

> 표가 비어있으면 자동 치환은 no-op. 새 합의가 누적된 시점부터 작동.
