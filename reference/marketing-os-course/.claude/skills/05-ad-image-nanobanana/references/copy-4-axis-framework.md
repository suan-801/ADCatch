# USP 4축 골격 — User's Pain Point · Solution · Creative Key Visual · Promotion (★ 카피·비주얼 도출 1차 풀)

> 본 파일은 04-brief-synthesizer 와 05-ad-image-nanobanana 의 **카피·비주얼 자동 도출** 단계에서 1차 후보 풀로 사용한다. 강의 5강 "USP 4축 — 가상 광고 1장으로 한눈에" 슬라이드 정의를 그대로 따라 광고 1장이 한눈에 읽히는 4축 구조로 합성.

## 0. 4축 마스터 정의

| 축 | 라벨 | 의미 | 인풋 출처 | 카피 / 비주얼 |
|---|---|---|---|---|
| ① | **User's Pain Point** | 고객의 진짜 페인·상황 후킹 (0~3초 시선 멈춤) — 의문문 변환 우선 | `pain_points.md` § 5 페인 단어 + § 4 페어링 Set A 의 1단 페인 | **카피** |
| ② | **Solution** | 그 페인을 해결하는 자사 USP + RTB (임상·권위·숫자) + 욕구 충족 결과. 한 줄로 USP 약속을 + 작은 글씨로 임상 근거 1줄 | `brand_brief.md` § USP 1순위 + § RTB · 임상 + `pain_points.md` § 1 욕구 Top 3 + `competitor_ads.md` 사회증거 패턴 | **카피** |
| ③ | **Creative Key Visual** | 메시지 3축(①②④)을 1컷에 모은 비주얼 — 카테고리 노이즈를 뚫는 핵심 비주얼 1컷 (제품·시각·라이프스타일·인포그래픽) | `brand_brief.md` § 비주얼 6슬롯 + `01_brand/products/` reference + `02_competitor/competitor_ads.md` § 시각 트렌드 빈틈 | **비주얼** |
| ④ | **Promotion** | 혜택·할인·증정 + CTA — 행동을 만드는 압력. **혜택 최대 2개 (3개 ❌)** · 환불·배송은 ② Solution RTB 또는 ③ 인증 뱃지로 분리. 02 경쟁사 평균 자수 8~13자 (`copy-char-caps.md § 3-1`) | `brand_brief.md` § 가격·메인 오퍼 + `cta-library.md` 호기심 유발형 5종 | **카피 (CTA 포함)** |

### 페어링 3세트 ↔ 4축 매핑 (★ 03-pain-from-reviews 와의 다리)

`pain_points.md` § 4 의 페어링은 "페인↔욕구↔USP" 의 광고 골격 (3축). 4축은 그 골격을 카피·비주얼 표면으로 풀어낸 4칸. 매핑:

| 페어링 | 4축 | 변환 방식 |
|---|---|---|
| 페어링 1단 (페인) | **① User's Pain Point** | 의문문 변환 (예: "5분 만에 날아간 적 있으셨죠?") |
| 페어링 3단 (근거·USP) + 페어링 2단 (약속·욕구) + 임상 RTB | **② Solution** | USP 한 줄 약속 + RTB 한 줄 (임상%·1위·인증) 결합 |
| (페어링에 없음 — brand_brief + reference) | **③ Creative Key Visual** | 제품컷·비주얼 시드 |
| (페어링에 없음 — brand_brief + cta-library 인풋) | **④ Promotion** | 가격·할인·증정·리스크 제거 + 호기심 CTA 1개 |

## 1. 5개 시그니처 골격 (A~E)

K-뷰티 광고 카피는 다음 5개 골격 중 1개를 기반으로 한다. 시안 1장 = 골격 1개. 골격 슬롯은 4축 구조 (① Pain Point · ② Solution · ③ Creative Key Visual · ④ Promotion+CTA) 에 매핑.

### 골격 A — 임상수치 + 1위 + 할인 (DOMINANT · K-뷰티 디폴트)

```
[① 페인 의문문] / [② 성분·USP 한 줄 + 임상 % + 1위 메커니즘] / [③ 제품 히어로 + 임상 수치 시각화] / [④ 할인 + 증정 + 호기심 CTA]
```

- 적합: 신뢰·결과 소구 (안티에이징·미백·집중케어). K-뷰티 광고에서 가장 빈도 높음.
- 예: `30대 잡티가 더 진해진다면? / 데일리 브라이트닝 세럼 — 임상 입증 · 카테고리 상위 / 제품 정면 + 핵심 수치 큰 강조 / 런칭 35% OFF + 미니어처 증정 — 지금 시크릿 가격 확인 ›`

### 골격 B — 공감 페인포인트 (소프트)

```
[① 페인 상황 질문] / [② 솔루션 한 줄 USP + 작동 원리 + 욕구 충족] / [③ 제품 + 사용 신] / [④ 1+1 시크릿 특가 + CTA]
```

- 적합: 페인이 명확한 카테고리 (잡티·기미·여드름·민감성). 친근 톤.
- 예: `좁쌀여드름이 또 올라왔다면? / 진정 세럼 — 바르면 톡 흡수되며 진정 + 모공 케어 / 손바닥 위 텍스처 매크로 / 1+1 시크릿 특가 — 이번 주만 받는 가격 ›`

### 골격 C — 망설임 격파 + 안전성 약속

```
[① X 없이/X 안 떠요/X 가릴 필요 없는 페인 회피] / [② 그러면서도 X 효과 USP + 임상 + 환불 보장] / [③ 인증 뱃지 + 제품] / [④ 할인 + CTA]
```

- 적합: 카테고리 진입 장벽 격파 (자극·끈적임·들뜸·하얗게 뜸).
- 예: `자극 없이 케어 가능할까요? / 순한 비건 세럼 — 임상 입증 · 자극 0건 · EWG 그린 / 제품 + V-Label·EWG 뱃지 / 30일 환불 보장 + 미니어처 증정 — 이 링크에서만 받는 가격 ›`

### 골격 D — 호기심 후크 + 비밀가격

```
[① 감탄·역설 후크 (페인 변형)] / [② 한정 키워드 USP + 임상 RTB] / [③ 호기심 시각 후크 — 검은 박스·블러] / [④ 비밀 가격 + CTA]
```

- 적합: 신규·런칭·한정 기획. 호기심 자극이 핵심.
- 예: `흔한 데일리 케어를 거부합니다 / 집중 리셋 세럼 — 임상 입증 · 펀딩 인기 / 제품 + 핵심 키워드 큰 강조 / 회원만 받는 시크릿 가격 ›`

### 골격 E — 시그니처 성분 해시태그

```
[① #성분명 #카테고리템 (페인 코드)] / [② 성분 + 카테고리 USP + 임상 + 1위] / [③ 성분 원물 + 제품 듀오] / [④ 채널 단독 가격 + CTA]
```

- 적합: 성분 카테고리 점유 (#비타민C #나이아신 #레티놀 #카로틴).
- 예: `#비타민세럼 #데일리케어 / 핵심 성분으로 매일 톤 케어 — 임상 입증 · 카테고리 상위 / 성분 원물 + 세럼 병 / 채널 단독 시크릿 가격 — 한정 수량 확인 ›`

## 2. Creative Key Visual 비주얼 적층 (★ ③축 의무)

4축 중 ③ Creative Key Visual 은 카피가 아닌 **비주얼 1축** 이다. NanoBanana 프롬프트 [1]~[5] 블록의 시각 묘사에 직행하는 비주얼 시드. 다음 4슬롯이 모두 시안 1장에 등장해야 K-뷰티 적층 충족:

| 슬롯 | 내용 | 인풋 |
|------|------|------|
| **제품 시각** | 자(jar) 정면 + 매크로 디테일 (세럼·텍스처) | `brand_brief.md` § 제형 묘사 + `01_brand/products/` reference 이미지 |
| **컬러 팔레트** | 6슬롯 (BG-Light · BG-Deep · BRAND-Signature · BRAND-Sub · TEXT-Primary · TEXT-Sub) | `brand_brief.md` § 비주얼 6슬롯 |
| **뱃지·인증** | VEGAN · EWG · 임상 % · 환불 보장 4종 | `brand_brief.md` § trust-badges OCR |
| **시각 마커** | 화살표·서클·언더라인·해시태그 (텍스트 보충) | NanoBanana 프롬프트 [4] TEXT EFFECT |

> 슬롯 4개가 모두 시안 1장에 등장해야 K-뷰티 적층 충족. 텍스트로 다 못 담으면 시각 마커·뱃지로 시각 등가물 보충.

## 3. 카피 후보 도출 방식 (시드 3축)

1차 카피 후보 6~9개를 다음 3축에서 각 2~3개씩 만든다. 각 후보는 골격 A~E 중 어느 골격을 기반으로 했는지 표기.

| 축 | 도출 방식 | 매핑 골격 |
|---|---|---|
| **페인 → Solution (①·②)** | 고객 페인 Top 5 × 자사 USP 매칭. 페인을 의문문으로 변환한 헤드라인 + USP 약속 | B / C |
| **욕구 → Solution (②)** | 고객 욕구 Top 3 × 자사 RTB·임상. USP 가 욕구를 어떻게 충족하는지 설명 | A / E |
| **경쟁사 빈틈 → 차별 Solution (②)** | 경쟁사가 다루지 못한 RTB·임상·사회증거 | A / D |

각 후보는:
- **헤드라인 (User's Pain Point) 1줄** (≤15자, `copy-char-caps.md` 참조)
- **기반 골격** — A/B/C/D/E 중 1개
- **출처** — `pain_points.md` 페인 #N / `brand_brief.md` USP #M / `competitor_ads.md` 행 K
- **이유** — 왜 이게 강한가 1줄

## 4. 후보 → 최종 1개 압축

6~9개 후보 중 가장 강한 1개를 선택 (디폴트는 페인↔USP 매칭이 가장 명확한 후보). 검수·치환 순서:

1. **자수 캡** (`copy-char-caps.md`) — Pain Point ≤15자 / Solution ≤26자 (≤13자 × 2줄) / **Promotion 혜택 ≤12자 (혜택 최대 2개)** + CTA ≤10자
2. **금지어 검수** (`banned-words.md`) — "드라마틱한 변화" → "드라마틱한 변화 없으셨죠?" 의문문 변환
3. **자기 발등 점검** — `pain_points.md` § 6 의 자사도 가진 페인이 ① Pain Point 로 들어갔는지 cross-check
4. **CTA 치환** (`cta-library.md`) — Promotion 안의 CTA 풀바에 가격 직접 노출 ❌, 호기심 유발형 5종 중 1개
5. **★ Promotion 강제 압축** (`copy-char-caps.md § 3-1`) — 혜택 ≥ 3개면 우선순위로 1~2개만 (① 가격 수치 ≫ ② 사은품 ≫ ③ 시급성 ≫ ④ 신뢰). 환불·배송·임상 안전 안내는 ② RTB 슬롯 또는 ③ 인증 뱃지로 분리. 02 경쟁사 평균 자수 8~13자 기준

최종 4축은 in-memory 변수로 보유 → NanoBanana 프롬프트 [4] TEXT EFFECT 블록 큰따옴표 인용으로 직행. **디스크 저장 ❌** (분기 A 의 `confirmed_brief.md` 가 아닌 한).
