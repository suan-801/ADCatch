# Page Type — 단일 상품 LP

> 목적: 단일 상품·서비스의 핵심 가치를 1페이지로 전달 → 상세 페이지 / 구매 / 사전 등록으로 유도.
> SKILL Step 1.5 에서 페이지 타입이 "단일" 일 때 본 파일을 1순위 인용.
> 또한 페이지 타입이 명시되지 않았을 때의 **디폴트** 골격.

---

## 1. 필수 섹션 골격 (이 순서, 5개)

```
1. Hero                  메인 카피 + 핵심 약속 + 제품 비주얼 + CTA
2. USP 3가지             브랜드의 핵심 약속 3개 (brand_brief § USP 인용)
3. 사회증거 (Proof)       임상·후기·판매·미디어 인용
4. 디테일 (How / What)   사용법·성분·시나리오 — 1~2섹션
5. Final CTA             자세히 보기 / 구매하러 가기
```

> 5개 섹션 = 가장 가벼운 골격. 메시지 풍성하면 디테일 (4) 을 2섹션으로 확장 가능 (총 6).

---

## 2. 섹션별 카피 골격 + 레이아웃 옵션

### 2-1. Hero
- **헤드라인**: "{핵심 약속}" — 결과 중심 (예: "N주 만에 환해지는 브라이트닝 세럼")
- **서브카피**: "{정량 근거 1개} + {타겟 페인 1개}" (예: "임상 완료 미백 1위 · 기미·잡티 고민")
- **CTA**: "자세히 보기" 또는 "구매하러 가기" (cta-library.md § 1-3)
- **보조 카피**: (선택) "리뷰 N건 / 누적 판매 N개"
- **레이아웃**: `Split-screen hero` (제품 + 카피 균형) 또는 `Full-bleed image hero`
- **이미지**: 히어로 16:9 — 제품 단독 또는 라이프스타일 (NanoBanana + 제품 reference AS-IS)

### 2-2. USP 3가지
- **헤드라인**: "{브랜드명}의 핵심" 또는 "{SKU} 가 다른 이유"
- **카드 3장 (brand_brief.md § USP Top 3 그대로 인용)**:
  - **USP 1**: 페이지 USP § 1 + 정량 근거
  - **USP 2**: 페이지 USP § 2 + 정량 근거
  - **USP 3**: 페이지 USP § 3 + 정량 근거
- **레이아웃**:
  - `Bento grid` (1개가 메인 USP + 보조 2개 — 가중치 다를 때)
  - `Icon-led columns` (균일 가중치 3개)
  - `Alternating left/right blocks` (이미지·텍스트 좌우 교대 — 콘텐츠가 풍부할 때)

### 2-3. 사회증거 (Proof)
- **헤드라인**: "데이터로 증명" 또는 "고객 후기"
- **포맷 옵션** (택 1 또는 2):
  - **Stats**: brand_brief § USP 의 정량 수치 트리오 (3개 숫자) — 예: "120% / 89% / 4주"
  - **Testimonial**: 후기 3개 (별점 / 인용 / 사용 기간)
  - **Media badge**: "펀딩 1위", "채널 베스트" 등 (있을 때만)
- **레이아웃**:
  - `Dark strip` (숫자 강조 — 두 라이트 섹션 사이 break)
  - `Staggered cards` (후기 — 길이 다양)
  - `Stat cards row` (균일 카드 + 큰 숫자)

### 2-4. 디테일 (How / What)
- **헤드라인**: "어떻게 작동하나" / "성분·사용법"
- **포맷 옵션** (택 1):
  - **사용 시나리오 4단계**: "세안 → 토너 → 본 세럼 → 보습"
  - **성분 카드 3~4개**: "비타민C / 나이아신아마이드 / 비타민 5종"
  - **비포 → 애프터** 또는 **타임라인** (N주 챌린지 같은 기간 약속)
- **레이아웃**: `Alternating left/right` (시나리오 단계) 또는 `Magazine grid` (성분 + 비주얼)

### 2-5. Final CTA
- **헤드라인**: "{핵심 약속 한 줄}" — Hero 의 약속을 클로징으로 재인용
- **CTA 버튼**: "구매하러 가기" / "자세히 보기"
- **보조 카피**: (선택) "리뷰 N건 · 별점 평균 N" 또는 "오늘 출고 / 무료배송"
- **레이아웃**: `Minimal` (단순 클로징) 또는 `Image-backed` (브랜드 컬러 충만)

## 3. 이미지 슬롯 (NanoBanana 호출 계획)

| 슬롯 | 비율 | 프롬프트 시드 | output_path |
|---|---|---|---|
| `hero` | 16:9 | 제품 풀블리드 또는 라이프스타일 (브랜드 무드) | `08_landing/{토픽}/images/hero.png` |
| `content-1` | 4:3 | 제품 클로즈업 (USP 또는 성분 시각화) | `08_landing/{토픽}/images/content-1.png` |
| `content-2` | 4:3 | (선택) 사용 시나리오 또는 비포애프터 | `08_landing/{토픽}/images/content-2.png` |

총 2~3장. 제품·로고 등장 시 `01_brand/products·logos/` AS-IS reference 필수.

## 4. 단일 LP 디자인 컬러 운용 (brand_brief § 4-1 6슬롯)

| 영역 | 슬롯 |
|---|---|
| 페이지 전체 배경 | BG-Light |
| Hero·Final CTA 풀블리드 | BG-Deep 또는 BRAND-Signature |
| 본문 텍스트 | TEXT-Primary |
| 보조 텍스트·라벨 | TEXT-Sub |
| CTA 버튼 | BRAND-Signature |
| 카드 그라데이션 보더·강조 | BRAND-Sub |

페이지 안에서 **6슬롯 모두 사용 권장** (한 슬롯이라도 사용되지 않으면 Step 4 검수에서 경고).

## 5. 신청 / 구매 CTA URL 유형

단일 LP 의 CTA 외부 URL:
- **자사몰 상품 상세 페이지** — 카페24·아임웹·shopify·스마트스토어 (가장 일반적)
- **마켓 페이지** — 크라우드펀딩 (펀딩 진행 중)
- **사전 등록 폼** — 구글폼·Tally (런칭 전 단계)
- **앱 스토어** — 앱 서비스 (App Store / Google Play)

→ 모두 `<a href="..." target="_blank" rel="noopener noreferrer">` 단일 패턴.
