# Page Type — 이벤트 / 프로모션 LP

> 목적: 세일·신제품 런칭·1+1·사전등록·구독 프로모션 등 캠페인 LP → 참여 폼/상세 페이지로 유도.
> SKILL Step 1.5 에서 페이지 타입이 "이벤트" 일 때 본 파일을 1순위 인용.

---

## 1. 필수 섹션 골격 (이 순서, 6개)

```
1. Hero                  이벤트명 + 기간 + 메인 혜택 + CTA
2. 혜택 카드 (Value)      이벤트 혜택 3~4종 (할인·1+1·굿즈·무료배송 등)
3. 진행 방법 (How-to)     참여 절차 단계 (선택 — 단순 구매 이벤트는 스킵)
4. 사회증거 (Stats/Proof) 임상·후기·판매 수치 (있을 때만)
5. 유의사항 (FAQ 변형)    이벤트 조건·제외·환불 등 안내
6. Final CTA             지금 참여하기 + 마감 D-day
```

> ⚠️ **진행 방법 (3)** 은 단순 "구매 시 자동 적용" 이벤트면 스킵 → 5개 섹션. 사전등록·응모형·후기 참여형은 필수.
> ⚠️ **유의사항 (5)** 은 광고 표시 의무 (할인·번들·환불 조건) 대응. 작은 텍스트 OK 하지만 누락 ❌.

## 2. 섹션별 카피 골격 + 레이아웃 옵션

### 2-1. Hero
- **헤드라인**: "{이벤트명}" + "{메인 혜택}" (예: "4주 챌린지 1+1 / 정가 50%")
- **서브카피**: "{기간}" + "{핵심 조건}" (예: "5월 12일 ~ 5월 19일 · 1+1 무료배송")
- **CTA**: "혜택 받으러 가기" (cta-library.md § 1-2)
- **보조 카피**: "이벤트 마감 D-N"
- **레이아웃**: `Text-forward hero` (이벤트명·할인율이 주인공) 또는 `Full-bleed image hero`
- **이미지**: 히어로 16:9 — 제품 + 이벤트 무드 (NanoBanana 자동)

### 2-2. 혜택 카드 (Value Props)
- **헤드라인**: "이번 이벤트 혜택"
- **카드 3~4장**:
  - **혜택 1 (메인)**: "정가 N% 할인" 또는 "1+1 / 2+1"
  - **혜택 2**: "무료배송"
  - **혜택 3**: "추가 굿즈 / 사은품"
  - **혜택 4 (선택)**: "회원 적립 N% / 첫 구매 추가 N%"
- **레이아웃**:
  - `Overlapping cards` (혜택 강조 — 메인 후킹일 때) — Hero 위 negative margin
  - `Bento grid` (혜택 1이 메인 + 보조 3개)
  - `Icon-led columns` (균일 가중치)

### 2-3. 진행 방법 (How-to) — 응모/사전등록형만
- **헤드라인**: "이벤트 참여 방법"
- **단계 3~4**:
  ```
  Step 1 — 사전등록 / 이메일 입력 1분
  Step 2 — 알림 받기 / 런칭 D-day
  Step 3 — 우선 구매 + 혜택 적용
  ```
- **레이아웃**: `Icon grid` 또는 `Timeline`

### 2-4. 사회증거 (Stats / Proof)
- **헤드라인**: "왜 4주 챌린지인가" 또는 "고객 후기"
- **포맷 옵션**:
  - **Stats**: brand_brief § USP 인용 (예: "120% / 89% / 4주" 3개 숫자)
  - **Testimonial**: 후기 3개 (별점·인용)
- **레이아웃**: `Dark strip` (숫자 강조) 또는 `Staggered cards` (후기)

### 2-5. 유의사항 (FAQ 변형)
- **헤드라인**: "유의사항"
- **리스트 형태 또는 아코디언**:
  - "이벤트 적용 조건 (회원 / 첫 구매 / 특정 SKU 등)"
  - "쿠폰 중복 사용 여부"
  - "환불·교환 정책"
  - "이벤트 종료 후 가격 복원"
  - (광고 의무) "표시 가격은 부가세 포함" 등
- **레이아웃**: 작은 텍스트 (`font-size: 13px; color: var(--text-sub);`) 박스 형태. `<details>` 아코디언 권장.

### 2-6. Final CTA
- **헤드라인**: "지금 참여하세요" / "이번 주만"
- **CTA 버튼**: "혜택 받으러 가기" 또는 "지금 참여하기"
- **보조 카피**: "이벤트 마감 D-N · 자정 종료"
- **레이아웃**: `Dark immersive` 또는 `Image-backed`

## 4. 카운트다운 — 신중

이벤트 마감일이 있으면 D-day 정적 표기 권장:
```html
<p class="btn-meta">이벤트 마감 D-<span id="dday">3</span></p>
```

**실시간 타이머 (00:00:00:00) 는 banned-words.md § 3 위반 — 기본 ❌**.
brand_brief § 톤 Always 에 명시적으로 "시크릿몰 톤" 이 있을 때만 면제.

## 5. 광고 표시 의무 체크리스트

이벤트 LP 는 광고 표시 관련 의무 조항이 있을 수 있다. **사용자 확인 필요**:

- [ ] 가격 표기 시 "부가세 포함" 또는 "별도" 명시
- [ ] 할인 표기 시 "정가 대비 N% 할인" 또는 "회원가" 구분
- [ ] 사은품 표기 시 "재고 소진 시 종료" 또는 "선착순 N명"
- [ ] 임상·효능 표기 시 "임상 N명 / N일 / N% (출처)" 정량
- [ ] "추천 / 베스트" 표기 시 근거 (어느 플랫폼 / 어느 기간)

이 항목들은 § 5 유의사항 섹션에 작은 텍스트로 포함.

## 6. 신청 / 참여 CTA URL 유형

- **사전등록 / 응모형**: 구글폼, Tally, Wisha (가장 일반적)

- **이메일 알림**: 자체 뉴스레터 폼 URL
