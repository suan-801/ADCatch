# Page Type — 체험단 모집 LP

> 목적: 제품 체험단·서포터즈 모집 → 신청 폼(구글폼/Tally) 으로 유도.
> SKILL Step 1.5 에서 페이지 타입이 "체험단" 일 때 본 파일을 1순위 인용.

---

## 1. 필수 섹션 골격 (이 순서, 7개)

```
1. Hero                    체험단 모집 메인 카피 + 신청 CTA + 모집 마감 D-day
2. 혜택 (Value Props)       체험단에게 주는 것 3종 (제품 / 활동비 / 추가 굿즈 등)
3. 진행 일정 (How-it-works) 신청 → 선정 → 발송 → 활동 → 마감 단계 표
4. 신청 자격                연령·인원·SNS 활동 조건 등 카드 리스트
5. 사회증거 (선택)           이전 체험단 후기·인증샷·임상 수치
6. FAQ                     자주 묻는 질문 3~5개
7. Final CTA               지금 신청하기 + 마감 D-day + 잔여 인원
```

> ⚠️ **사회증거 (5)** 는 첫 모집이면 스킵. 2차 이상 모집이면 이전 활동 후기·인증샷 인용 (사용자가 자산 제공).

## 2. 섹션별 카피 골격 + 레이아웃 옵션

### 2-1. Hero
- **헤드라인**: "{브랜드명} {SKU 또는 캠페인} 체험단 모집" 또는 "{결과 약속} 4주 챌린지 체험단"
- **서브카피**: "{정량 근거 1개} + {모집 인원}" (예: "임상 완료 광채 세럼 · 50명 한정")
- **CTA**: "지금 신청하기" (cta-library.md § 1-1 인용)
- **보조 카피**: "모집 마감 D-N · 잔여 N명"
- **레이아웃**: `Full-bleed image hero` 또는 `Split-screen hero` (layout-toolkit.md § 1-1)
- **이미지**: 히어로 16:9 — 제품·라이프스타일 (NanoBanana 자동)

### 2-2. 혜택 (Value Props)
- **헤드라인**: "체험단 혜택"
- **카드 3장 (필수)**:
  - **혜택 1 — 제품**: "{SKU} 풀세트 무료 제공" + 가격 환산 ("정가 N만원 상당")
  - **혜택 2 — 활동비 또는 굿즈**: "활동비 N만원" 또는 "추가 굿즈 N종"
  - **혜택 3 — 우선권 또는 후기 노출**: "재구매 N% 할인권" / "인스타 본 계정 노출"
- **레이아웃**: `Icon-led columns` 또는 `Bento grid` (혜택 1이 메인이면 bento)

### 2-3. 진행 일정 (How-it-works)
- **헤드라인**: "진행 일정"
- **단계 4~5**:
  ```
  Step 1 — 신청서 작성 / N월 N일 ~ N일
  Step 2 — 발표 / N월 N일 (이메일 + SNS DM)
  Step 3 — 제품 발송 / N월 N일
  Step 4 — 체험 + 후기 작성 / N일간
  Step 5 — 활동 마감 / N월 N일
  ```
- **레이아웃**: `Timeline` (가로 5단계 권장) 또는 `Numbered vertical stack`

### 2-4. 신청 자격
- **헤드라인**: "신청 자격"
- **카드 또는 리스트** (4~6개):
  - 연령·성별 조건 (예: "20~40대 여성")
  - 피부 타입 (있다면)
  - SNS 활동 조건 (예: "인스타그램 1주 1회 이상 활동")
  - 후기 의무 (예: "활동 기간 후기 N건 작성")
- **레이아웃**: `Icon-led columns` 2x2 또는 1x4

### 2-5. 사회증거 (선택, 2차 모집 이상)
- **헤드라인**: "지난 체험단의 후기"
- **포맷**: 인스타 인증샷 그리드 또는 후기 카드 3장
- **레이아웃**: `Magazine grid` 또는 `Staggered cards`

### 2-6. FAQ
- **헤드라인**: "자주 묻는 질문"
- **3~5개 질문**:
  - "선정 기준이 어떻게 되나요?"
  - "제품은 언제 받을 수 있나요?"
  - "후기는 어디에 작성해야 하나요?"
  - "활동비는 언제 지급되나요?" (해당 시)
  - "중도 포기 시 어떻게 되나요?"
- **레이아웃**: `<details><summary>` 아코디언 (CSS 만, JS ❌)

### 2-7. Final CTA
- **헤드라인**: "지금 신청하세요" / "마지막 N명의 자리"
- **CTA 버튼**: "지금 신청하기"
- **보조 카피**: "모집 마감 D-N · 잔여 N명"
- **레이아웃**: `Dark immersive` 또는 `Image-backed`

## 4. 옵션 — 카운트다운

체험단 모집은 "모집 마감 D-N" 정도가 적절. **실시간 카운트다운 타이머 (00:00:00) ❌** (banned-words.md § 3 위반).

D-day 정적 표기 (HTML 직접 작성). 사용자가 명시 요청 시만 JS 카운트다운 추가:
```html
<span id="dday">D-3</span>
<script>
  const target = new Date('2026-05-20T00:00:00+09:00');
  const days = Math.max(0, Math.ceil((target - new Date()) / 86400000));
  document.getElementById('dday').textContent = `D-${days}`;
</script>
```

## 5. 신청 CTA URL 유형

체험단 모집에서 가장 많이 쓰이는 외부 폼:
- **Google Forms** — 무료, 간단. URL 예: `https://forms.gle/...`
- **Tally** — UX 우수. URL 예: `https://tally.so/r/...`
- **Naver Form** — 한국 사용자 편의. URL 예: `https://naver.me/...`
- **자체 CMS** — 카페24·아임웹·shopify 등 (URL 받음)

→ 모두 `<a href="..." target="_blank" rel="noopener noreferrer">` 단일 패턴으로 동일 처리.
