# Copy Rules — LP 카피 톤·자수 캡·구체 명사

> SKILL Step 1.5 (시나리오 도출) 와 Step 4 (Self-Validate) 의 1순위 검수 기준.
> 브랜드 톤은 `01_brand/brand_brief.md § 톤 (Always 3 / Never 3)` 가 ground truth — 본 파일은 그것 위에 한국어 LP 일반 룰을 얹는다.

---

## 1. 글로벌 톤 원칙

✅ **이렇게 쓴다**
- **구체 명사** 우선 — "관리" → "4주 챌린지", "성분" → "비타민C 10% + 나이아신아마이드 5%"
- **짧은 단언문** — 리듬: 짧게, 짧게, 조금 길게
- **숫자 트리오** — 임상·후기·기간 등 정량을 3개 묶음으로 (brand_brief § USP 인용)
- **혜택을 판다** — 기능 ("성분 5종") 이 아니라 결과 ("4주 만에 잡티 면적 84% 개선")
- **2인칭 자연어** — "당신" 보다 한국어 LP 에서는 무주어 또는 직접 호명 ("기미 고민 있으세요?")

❌ **이렇게 안 쓴다**
- **과장 형용사 단독** — "혁신적", "놀라운", "최고의" — 구체적 근거 없이 사용 금지
- **느낌표 남발** — 페이지 전체 1개 이하. CTA 외 본문 ❌
- **의약품 연상** — "치료", "100% 보장", "완치" 금지 (화장품법)
- **절박·불안 조성** — "마지막 기회", "🚨", 카운트다운 타이머 (시크릿몰 톤은 본 OS 디폴트 ❌. brand_brief § 톤 Never 인용 시만)
- **제너릭 CTA** — "지금 클릭", "여기를 누르세요" — 혜택과 묶이지 않은 행동만

## 2. 자수 캡 (페이지 타입 무관 공통)

| 슬롯 | 자수 캡 | 비고 |
|---|---|---|
| **Hero 헤드라인** | ≤ 20자 (한 줄), ≤ 30자 (2줄 분할) | 거대 타입스케일 — 길면 시각 임팩트 ❌ |
| **Hero 서브카피** | ≤ 60자 (1~2줄) | 헤드라인 보강·근거 1개 |
| **섹션 헤드라인** | ≤ 24자 | 섹션의 약속 |
| **혜택·USP 카드 헤드** | ≤ 12자 | 라벨처럼 간결 |
| **혜택·USP 카드 본문** | ≤ 60자 | 1~2줄 |
| **FAQ 질문** | ≤ 30자 | |
| **FAQ 답변** | ≤ 120자 | 한 단락 |
| **CTA 버튼** | ≤ 10자 | "지금 신청하기" / "혜택 받으러 가기" |
| **CTA 보조 카피** | ≤ 30자 | 버튼 아래 1줄 — 마감일·인원 등 |

> 자수는 한국어 기준. 영문 헤드라인 (브랜드 라벨 톤) 은 별도 — brand_brief § 4-4 폰트 가이드 따른다.

## 3. 어미·문체 가이드

✅ **권장 어미**
- **체언 종결** — "4주 챌린지." (마침표 생략 옵션) — Hero/카드 헤드에 깔끔
- **~합니다 / ~합니다체** — FAQ·신청 자격·유의사항 본문에 (LP 톤은 존대)
- **~세요 / ~요** — CTA 보조 카피, FAQ 답변 끝 — 친근

❌ **회피 어미**
- **~다 (반말)** — LP 본문 ❌. 자기소개 매뉴얼 톤 ❌
- **~인 것 같습니다 / ~수도 있습니다** — 자신감 부족
- **~할 수 있습니다** — 가능성 표현. "~합니다" 로 단언 가능하면 단언
- **이중부정** — "~하지 않을 수 없다" ❌
- **번역투** — "~에 있어서", "~에 다름 아닙니다", "~에 대하여" → 한국어 자연 표현으로

## 4. 섹션별 카피 골격

### 4-1. Hero
```
[헤드라인]   {구체 명사} + {결과 약속}
[서브카피]   {정량 근거 1개} + {타겟 페인 1개}
[CTA]        {행동 동사} + {혜택}
```
예 (체험단):
> 4주 챌린지 체험단 모집
> 잡티·기미 임상 완료. 50명 한정.
> [지금 신청하기]

### 4-2. 혜택 / Value Props
```
[카드 헤드]  {한 단어 + 숫자 또는 라벨}
[카드 본문]  {구체 + 결과}
```
예:
> **혜택 1 / 정가 50%**
> 4주 챌린지 풀세트(50ml × 2) 무료 제공

### 4-3. 사회증거 / Stats
```
[숫자]   {정량 — brand_brief § USP 인용}
[라벨]   {숫자가 의미하는 바}
```
예:
> **120%**
> 임상 완료 — 피부 밝기 개선

### 4-4. How-it-works (체험단·이벤트)
```
[단계 번호]  Step 1
[헤드라인]   {동사} + {대상}
[본문]       {기간} + {요구사항}
```
예:
> Step 1 / 신청서 작성
> 아래 폼에서 1분 안에 완료

### 4-5. Final CTA
```
[클로징 헤드]  {감정·약속 한 줄}
[보조 카피]    {마감·인원 정량}
[CTA 버튼]    {행동 + 혜택}
```
예:
> 4주 후 거울 앞에서.
> 모집 마감 D-3 · 잔여 12명
> [지금 신청하기]

## 6. 검수 체크리스트 (Step 4 자동)

- [ ] 헤드라인에 구체 명사 (브랜드명 / SKU / 정량) ≥1개 인가
- [ ] 페이지 전체 느낌표 ≤ 1개 인가
- [ ] CTA 버튼이 혜택과 연결된 동사구인가 (제너릭 "클릭" ❌)
- [ ] 자수 캡 (Hero ≤20자, CTA ≤10자 등) 준수인가
- [ ] brand_brief § 톤 Never 의 어휘가 본문에 없는가 (시크릿몰 톤·의약품 연상)
- [ ] 어미가 ~합니다 / ~세요 톤으로 통일 (반말 ❌)
- [ ] 구체 명사 치환 표의 모호 표현 잔존 여부
- [ ] `banned-words.md` 의 금지어 자동 치환 통과

위반 1개라도 있으면 v1 출력 전 in-memory 수정.
