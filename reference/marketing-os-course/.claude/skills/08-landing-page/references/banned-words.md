## 카테고리별 금지 단어

### 1. 제형·성분 묘사 (영문식 표현)

| ❌ 금지 | ✅ 대안 | 비고 |
|---|---|---|
| 비드 / 캡슐 비드 | **캡슐**, **톡 터지는 캡슐**, **캡슐 알갱이** | 영문식 어색. 05·07 공유 룰 |

### 2. 의약품 연상·과장 단정 (화장품법)

| ❌ 금지 | ✅ 대안 | 비고 |
|---|---|---|
| 치료 / 완치 / 효능 | 케어 / 진정 / 결과 | 화장품법 의약품 연상 ❌ |
| 100% / 무조건 / 절대 | "임상 N% (출처)" / "X일 만에" | 출처·정량 표기 의무 |
| 기적 / 마법 / 신세계 | 페인 + 결과 수치 | 객관 근거 우선 |
| 부작용 없음 | "민감성 피부 저자극 테스트 완료" | 의약품 톤 ❌ |

### 3. 절박·불안 조성 톤 (LP 특화)

| ❌ 금지 | ✅ 대안 | 비고 |
|---|---|---|
| 마지막 기회 / 단 한 번 | "선착순 N명 / 모집 마감 D-N" | 정량으로 긴급성. 가짜 절박 ❌ |
| 🚨 / ⚠️ (본문 데코) | (삭제) | brand_brief 시크릿몰 톤 ❌. [브랜드명] 정체성과 충돌 |
| "비밀 / 시크릿 / 회원만" | "체험단 한정 / 1차 모집" | 시크릿몰 톤은 본 OS 디폴트 ❌ |
| 카운트다운 타이머 (00:00:00) | D-day 표기 ("D-3") | 정적 표기로 갱신 부담 ↓ |

> **예외**: brand_brief § 톤 Always 에 명시적으로 "시크릿몰 톤 사용" 이 있을 때만 본 카테고리 면제. 디폴트는 위 룰.

### 4. 어미·격식 (LP 특화 — 카드뉴스와 반대)

| ❌ 금지 | ✅ 대안 | 비고 |
|---|---|---|
| ~다 / ~죠 (반말·구어) | ~합니다 / ~세요 | LP 는 카드뉴스보다 격식 ↑. 신청·이벤트 페이지는 존대 |
| 여러분~ / 고객님~ (과한 호명) | (호명 생략) | 거리감 ↓ |
| ~인 것 같습니다 | ~합니다 | 자신감 ↓ 표현 ❌ |

> ⚠️ 어미는 07 카드뉴스와 반대. LP 는 신청·결제 직전 단계라 격식 ↑.

### 5. 제너릭 CTA·과장 형용사 단독

| ❌ 금지 | ✅ 대안 | 비고 |
|---|---|---|
| "지금 클릭" / "여기를 누르세요" | "지금 신청하기" / "혜택 받으러 가기" | 혜택과 묶기 (cta-library.md) |
| "혁신적 / 놀라운 / 최고의" 단독 | (삭제 — 구체 근거로 대체) | 형용사 단독 ❌. 정량·구체 명사 |
| "프리미엄 / 트렌디한" | (삭제) | 구체 근거 없음 |
| "다양한 / 풍부한" | 정량 명시 ("3가지 / N개") | |

### 6. (예약) brand_brief Never 표현

> `01_brand/brand_brief.md § 톤 Never` 항목을 본 파일에 동적 인용. 브랜드별 다름. 예) [브랜드명] — "종료 임박", "🚨", "비밀", 형광 컬러.

### 7. 스크롤 시네마틱·인터랙션 금지 패턴 (★ 2026-05-11 신규)

> `layout-toolkit.md § 6 스크롤 시네마틱` 사용 시 동시 검수.

| ❌ 금지 패턴 | 이유 | ✅ 대안 |
|---|---|---|
| 수평 스크롤 캡처 (휠 → 좌우) | 사용자 방향 감각 손실, 모바일에서 망가짐 | 세로 스크롤 유지, sticky pin 으로 같은 효과 |
| 무한 스크롤 (LP 컨텍스트) | 푸터·CTA 도달 차단 | 명확한 페이지 끝 + Final CTA |
| 사운드 자동재생 | iOS Safari 차단·접근성 위반 | `<video muted playsinline>` 필수 |
| 스크롤 잠금 + 강제 풀스크린 애니메이션 (ESC 불가) | 사용자 통제 박탈 | sticky pin 으로 "잠긴 듯" 만, 실제 스크롤 자유 |
| sticky pin 트랙 > 300vh | 모바일에서 영상 1초가 페이지 1.5배 | sticky pin ≤ 200vh |
| 키프레임 재인코딩 없는 raw MP4 scrub | Safari·Chrome 에서 jerky stutter | `ffmpeg -g 1` 재인코딩 의무 |
| `perspective` < 1000px | 왜곡 심함, 멀미감 | perspective 1500~2000px |
| rotateY/rotateX > 10deg | 텍스트 가독성 손실 | 미세 틸트 (3~8deg) 가 세련됨 |
| 모바일 폴백 미적용 | iOS Safari currentTime scrub stutter | `matchMedia('(hover: none)')` 분기 → autoplay loop |

## 검수 절차 (★ 08 스킬에서 자동)

HTML 빌드 직전 (Step 3 → Step 4 사이):

1. Hero 헤드라인·서브카피
2. 모든 섹션 헤드·본문 (h2, h3, p)
3. 카드 헤드·카드 본문 (.card)
4. FAQ 질문·답변
5. CTA 버튼 텍스트 (.btn-primary, .btn-ghost)
6. CTA 보조 카피 (.btn-meta)
7. 푸터 카피

위 7곳에서 본 파일의 ❌ 단어 발견 시 **빌드 직전 자동 교체**. 별도 사용자 보고 ❌. v1 출력 후 채팅에 전체 카피를 동봉 → 사용자 자연 검수.

## 신규 단어 추가 시

사용자가 "X 단어 쓰지 말아줘" 식 룰성 피드백 시:

1. 카테고리 식별 (제형 / 의약품 / 절박톤 / 어미 / CTA / 기타)
2. 본 파일 해당 카테고리 표에 ❌ + ✅ 추가
3. 05·07 의 `banned-words.md` 와 공유해야 할 룰이면 (제형·의약품·brand_brief Never 카테고리는 보통 공유) 그쪽도 동기화
4. `CHANGELOG.md` 갱신
5. 현재 작업 중인 LP 는 v 증가하며 재빌드
