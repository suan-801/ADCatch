# 03_customer/reviews — 리뷰 원본 보관함

## 무엇을 넣는가

페인포인트·욕구 분석의 원천이 되는 **리뷰 원본** (URL이 막혔거나, 스크롤 펼침이 필요하거나, 캡처본만 있는 경우 사용).

| 카테고리 | 예시 |
|---|---|
| **경쟁사 PDP 리뷰** | 올리브영·쿠팡·자사몰의 베스트/최신순 리뷰 |
| **자사 리뷰** | 자사몰·펀딩몰·인스타 댓글 |
| **커뮤니티 VoC** | 화해·블로그·디시·X 인용 |

URL 만으로 분석 가능하면 이 폴더는 비워둬도 됩니다. URL이 동적 렌더링·로그인 벽 등으로 못 읽힐 때만 채우세요.

## 권장 파일명

```
{소스}_{제품명}_{별점or톤}_{날짜}.{확장자}

예)
oliveyoung_pdrn-pink_negative-1to3star_2026-04.txt   ← 텍스트 복붙
oliveyoung_pdrn-pink_positive-5star_2026-04.txt
coupang_skin-booster_screenshot_2026-04.png          ← 스크린샷
[브랜드명]_summer_funding-comment_2026-03.md             ← 펀딩몰 후기
```

## 어떤 형식이든 OK

- `.txt` — 리뷰 본문 복붙 (1줄=1리뷰 권장)
- `.md` — 별점/날짜/닉네임 포함 정리본
- `.png` / `.jpg` — 캡처 스크린샷 (멀티모달로 읽음)
- `.csv` — 스크래핑 결과

## 어디에 쓰이는가

- `/03-pain-from-reviews` 호출 시 이 폴더의 모든 파일을 **원본 인풋**으로 통합
- URL 인풋과 병행 가능 — 둘 다 있으면 합쳐서 분석
- 분석 결과는 `03_customer/pain_points.md` 1페이지로 요약

## 메타 (선택)

리뷰 출처별 별점 분포를 메모로 두면 분석 정확도↑.

```markdown
---
source: 올리브영 PDRN핑크
collected: 2026-04-15
total: 87건
star_dist: 5★ 52 / 4★ 18 / 3★ 8 / 2★ 5 / 1★ 4
---
```

- 자사 펀딩몰 서포터 후기를 인용할 땐 닉네임 익명화
