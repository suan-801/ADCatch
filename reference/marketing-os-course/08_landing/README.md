# 08_landing — 랜딩페이지

체험단·이벤트·단일 상품 LP 3타입을 NanoBanana(이미지) + HTML 단일 파일로 생성.

## 시작하기

```bash
/08-landing-page
```

> 사용자가 LP 타입과 컨셉을 자연어로 지시하면, 스킬이 신청 CTA (구글폼·Tally 외부 URL) 와 함께 자동 생성.

## 산출물 구조

```
08_landing/
└── {토픽-슬러그}/
    ├── index-v1.html      # 단일 파일 HTML
    └── images/
        ├── hero.png
        ├── content-1.png
        └── ...
```

- 토픽 슬러그: 영소문자 + 하이픈 (예: `launch-tester`, `1plus1-event`)
- 수정 요청 시 `index-v2.html`, `v3` 으로 버전 증가

> 본 폴더는 강의 3-4 (랜딩페이지) 의 산출물 저장소.
