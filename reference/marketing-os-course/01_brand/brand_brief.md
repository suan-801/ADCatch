# 메리츠화재 TM 사관학교 브랜드 브리프

> 소스: 채용 랜딩페이지 — https://store.meritzfire.com/direct-tm-recruit/IA-TMR.do#!/ (메리츠화재해상보험㈜)
> ⚠️ **도메인 주의**: 이 페이지는 일반 소비자 대상 제품 판매 PDP가 아니라 **구직자 대상 채용(HR) 랜딩페이지**입니다. "고객"은 상품을 사는 사람이 아니라 **TM(텔레마케팅) 보험설계사에 지원하는 구직자**이며, "구매"는 "지원(전화번호 남기기)"에 해당합니다. 이하 섹션은 이 맥락에 맞춰 작성했습니다.
> 페이지 구조: 전체 본문이 3장의 이미지(JPG/PNG, 세로 총 5,573px)로 구성된 이미지 기반 랜딩페이지 — curl 다운로드 + Claude Vision OCR로 전수 추출.
> ⚠️ 페이지 내 명시 고지: "*해당 사례는 실제 사례로 이미지는 AI로 생성된 가상 인물임" (후기 섹션 인물 사진은 AI 생성 이미지) / "*메리츠 MFP가 메리츠 TM 사관학교로 이름을 변경하였습니다" (구 명칭: 메리츠 MFP)

## 한 줄 정의

메리츠화재 본사가 직접 운영하는 TM(텔레마케팅) 보험설계사 육성 프로그램 "메리츠 TM 사관학교"는, 보험 경력이 전혀 없는 구직자에게 위촉 축하금 300만원 + 매일 고객 DB 제공 + 체계적 커리큘럼을 약속하며 "무경력도 고소득 커리어 시작"을 제안한다.

## USP 3개

1. **위촉 축하금 300만원** — 최근 3년 이내 보험 판매 무경력자 기준, 즉시 금전적 유인 제공 (단, 중도 이탈 시 분할 지급 조건)
2. **본사 직영 고객 DB 매일 제공** — 개척(콜드콜) 영업 부담 없이 시작 가능, "실력만 갖추면 되는" 구조
3. **체계적 커리큘럼 + 자격시험 지원 + 커리어 패스** — 입문 교육부터 영업관리자 등 커리어 확장까지 성장 경로 보장

## 타겟

- **Primary**: 보험 경력·영업 경험이 전혀 없는 구직자, 특히 경력단절 여성(주부)·중장년층. 후기 소재에 "딸에게 추천했다"는 모녀 서사를 사용해 신뢰·안전성을 강조
- **근무지 기반 타겟팅**: 서울(중구 서울역 인근)·부산(동구 부산진역 인근)·대구(수성구 범어역 인근) 통근 가능권 거주자
- **지원(전환) 결정 트리거**: "경력 없어도 정말 가능한가"라는 불안 해소(Q&A 1번 최우선 배치) + 초기 고정 수입(300만원 축하금)으로 리스크 헷지 + "5분만에 지원 가능"이라는 낮은 진입장벽

## 톤 — Always / Never

**Always**
- 친근한 구어체 존댓말 ("~해요", "~있어요", "~해보니까 너무 괜찮아서")
- 걱정 → 해소 순서의 스토리텔링 구조 (Q&A: "이래도 되나요?" → "네, 괜찮습니다" 패턴)
- 구체적 숫자로 신뢰 부여 (300만원, 3년, 5영업일, 5분, 3개 지역)

**Never**
- 전문 보험 용어·상품 스펙 나열 ❌ (이 페이지는 보험 상품이 아니라 "일자리"를 파는 카피)
- 하이엔드/럭셔리 톤 ❌ — 접근성·친근함이 우선
- 근거 없는 소득 과장 ❌ (페이지 스스로 "*소득은 회사기준 달성 시 가능"으로 조건부임을 명시)

### 사용 ❌ 컬러

- ❌ 병원/의료 연상 블루·그린 계열 — 보험이지만 "청구·심사" 느낌보다 "커리어 시작"의 밝고 따뜻한 톤이 페이지 전반의 방향
- ❌ 네이비·블랙 중심의 무거운 금융권 정장 톤 — 이 페이지는 의도적으로 파스텔·일러스트 아이콘(건물·헤드셋 캐릭터·악수) 톤 사용, 딱딱한 보험사 이미지 회피
- ❌ 무지개 그라디언트 / 4컬러 이상 그라데이션 — 실측 상 웜 핑크→크림 2톤 그라데이션이 전부
- ❌ 순수 회색조(무채색) 배경 단독 사용 — 항상 핑크 베이스(`BG-Light`)와 함께

### 폰트 + 스타일 묘사

- **폰트 패밀리**: `Pretendard, sans-serif` (computed style 실측 — body 전체 적용)
- **폰트 굵기**: 헤드라인은 굵은 산세리프(볼드~엑스트라볼드 추정), 본문은 medium(500) 기준
- **비주얼 스타일 묘사**: 사진(모델 인물·건물 외경)보다 **3D 일러스트 아이콘 + 라운드 카드 UI** 중심. 붉은 복주머니(코인 포함, "W" 로고 각인) 히어로 오브제, 둥근 모서리 화이트 카드 위에 아이콘+카피 배치, 섹션 구분은 배경색 전환(핑크↔화이트↔크림)으로 처리. 인물 사진은 후기 섹션 1곳에만 사용(AI 생성 이미지, 페이지 자체 고지).
