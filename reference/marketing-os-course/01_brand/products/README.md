# `01_brand/products/` — 제품 사진 넣는 곳

> 본인 브랜드 제품 사진을 이 폴더에 넣으세요. **파일명·서브폴더 자유** (영문·한글·`IMG_*.jpg` 모두 OK). 06 광고 이미지 스킬이 호출 시 자동 분류합니다.

---

## ★ 최소 필수 (없으면 06 스킬 호출 불가)

| 카테고리 | 설명 | 권장 컷 |
|---|---|---|
| **단품 정면 풀샷** | 제품 1개, 병/튜브/박스 전체 가시, **라벨 식별 가능**, 정면 또는 정면에 가까운 각도 | 1장 이상. 누끼 컷 (배경 제거) ❌ — 배경·그림자 살아있는 원본 |

→ 이 1장만 있으면 Hero·Discount·Proof·Review 등 단일 후킹 시안 6종 즉시 생성 가능.

---

## ★ 권장 (있으면 시안 다양화)

| 카테고리 | 설명 | 어느 시안에 쓰이나 |
|---|---|---|
| **라벨 매크로** | 라벨만 크게. 브랜드 워드마크·제품명·서브 카피·인증 마크 식별 가능한 클로즈업 | **모든 시안의 라벨 디테일 lock 용** (강력 권장 — 부재 시 AI 가 라벨 비율·폰트 매번 재해석) |
| **드로퍼·디테일·디스펜서 클로즈업** | 드로퍼·펌프·노즐·라벨 일부가 크게 잡힘. 손·물방울 동반 가능 | BeforeAfter / "한 방울" / 흡수 시연 시안 |
| **2제품 동시 컷** (듀오) | 같은 프레임에 제품 2개 (세럼+로션·본품+증정 등) | Bundle / 듀오 세트 시안 |
| **3+ 제품 라인업 컷** | 같은 프레임에 제품 3개 이상 (풀라인업·시리즈 컷) | 풀세트 시안 |
| **제형 매크로** | 액체·크림·젤 등 내용물 텍스처가 크게 잡힘 | 텍스처 / 성분 후킹 시안 |
| **라이프스타일·모델** | 모델·손·환경 (욕실·책상·여행) 과 함께 | (현재 매트릭스에서는 보조용. 메인 카테고리 ❌) |

## 파일명 가이드 (선택)

파일명에 카테고리 힌트가 들어가면 06 스킬의 1차 분류가 빨라집니다 (비전 호출 ❌ → 토큰 절약). 안 넣어도 비전 폴백이 자동 분류하므로 강제 ❌.

| 카테고리 | 권장 파일명 힌트 | 예시 |
|---|---|---|
| 단품 정면 풀샷 | `front`, `main`, `angle-01`, `정면`, `메인` | `serum-main-front.jpg`, `정면컷.png` |
| 드로퍼·디테일 | `dropper`, `pump`, `detail`, `closeup`, `드로퍼`, `디테일` | `dropper-detail.png` |
| 2제품 동시 (듀오) | `duo`, `pair`, `set-2`, `2pcs`, `듀오`, `세트2` | `duo-set.jpg` |
| 3+ 제품 라인업 | `lineup`, `family`, `fullset`, `라인업`, `풀세트`, `시리즈` | `family-lineup.png` |
| 제형 매크로 | `texture`, `formula`, `swatch`, `macro`, `제형`, `텍스처` | `texture-macro.jpg` |
| 라벨 매크로 | `label`, `라벨`, `label-macro` | `label-closeup.png` |
| 라이프스타일·모델 | `lifestyle`, `model`, `라이프스타일`, `모델` | `lifestyle-bathroom.jpg` |

서브폴더 컨벤션 (`main-angles/`, `studio/`, `lifestyle/`) 도 권장이지만 강제 ❌. 한 폴더에 다 넣어도 OK.

## 파일 포맷·해상도

- `.png` / `.jpg` / `.jpeg` / `.heic` / `.webp` 모두 수용
- 해상도: 가급적 1024px 이상 (라벨 텍스트 가독성 확보)
- 누끼 (배경 제거) PNG: 메인 컷 (단품 정면 풀샷) 으로는 ❌ — 배경·그림자 살아있는 원본 사용 (compositing 자연스러움). 보조 reference 로는 OK
