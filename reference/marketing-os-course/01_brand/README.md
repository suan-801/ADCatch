# 01_brand — 자사 브랜드 분석

본인 브랜드의 컨텍스트·로고·제품 이미지를 수집·정리하는 폴더.

## 시작하기

```bash
# 브랜드 홈페이지 URL 1개로 brand_brief.md 자동 생성
/01-brand-from-url https://{브랜드도메인}
```

## 산출물

| 경로 | 용도 |
|---|---|
| `brand_brief.md` | 1페이지 브랜드 브리프 (정체성·USP·톤·비주얼·메시지 후보) |
| `logos/` | 로고 PNG (NanoBanana reference image 로 사용) |
| `products/main-angles/` | 제품 정면·측면·상단·디테일 컷 |
| `products/lifestyle/` | 라이프스타일 컨텍스트 컷 |
| `products/studio/` | 스튜디오 무드 컷 |

> 본 폴더는 강의 2-1 (자사 브랜드 분석) 의 산출물 저장소.
